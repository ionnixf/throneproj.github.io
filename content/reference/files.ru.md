## Командная строка {#command-line}

| Параметр | Что делает |
| --- | --- |
| `-appdata` | Хранит данные в папке пользователя, а не рядом с программой. См. [Папка данных](#data-folder). |
| `-appdata <folder>` | Хранит данные в папке `config` внутри `<folder>`. |
| `-tray` | Запускает программу в трее, со скрытым окном. |
| Ссылка `throne://` | Обрабатывает ссылку так, как если бы вы щёлкнули по ней. См. [Глубокие ссылки](@/advanced/deeplinks.ru.md). |
| Пути к файлам или URL `file://` | Импортирует файлы, как `Программа` (Program) → `Добавить профиль из файла` (Add profile from File(s)). |
| `--headless` | Запускает Throne без окна, как службу или в контейнере. См. [Headless Throne](@/headless/_index.ru.md); его параметры описаны на странице [Командная строка и каталог данных](@/headless/command_line.ru.md). |
| `--check`, `--health`, `--print-connection` | Проверяют, может ли этот компьютер запускать headless Throne, запрашивают состояние работающего экземпляра или выводят настройки для `thronectl`. |

```bash
./Throne -appdata "$HOME/throne-test"
```

```powershell
.\Throne.exe -appdata D:\ThroneData
```

- Для одной папки данных может работать только один Throne. Повторный запуск передаёт ссылку или файлы работающему Throne и выводит его окно на передний план. Если папку использует headless Throne, новый запуск показывает «Throne работает в фоновом режиме» (Throne is running in the background) и завершается; см. [Устранение неполадок](@/help/troubleshooting.ru.md#background-throne).
- **macOS:** чтобы передать параметры, запустите программу внутри пакета приложения: `/Applications/Throne.app/Contents/MacOS/Throne -tray`.

## Папка данных {#data-folder}

Throne хранит ваши данные в папке с именем `config`. Открыть её можно через `Настройки` (Settings) → `Открыть папку конфигурации` (Open Config Folder) (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

| Способ установки Throne | Папка данных |
| --- | --- |
| ZIP для Windows или Linux | `config` в распакованной папке `Throne` (портативный режим) |
| Установщик Windows, для текущего пользователя (по умолчанию) | `config` в папке установки (портативный режим), по умолчанию `%LOCALAPPDATA%\Throne\config` |
| Установщик Windows, для всех пользователей | `%LOCALAPPDATA%\Throne\config` каждого пользователя |
| `.deb`, `.rpm` или скрипт установки для Linux | `~/.config/Throne/config` или `$XDG_CONFIG_HOME/Throne/config`, если задана переменная `XDG_CONFIG_HOME` |
| macOS | `~/Library/Preferences/Throne/config` |

- Портативная копия, запущенная с `-appdata`, использует папку пользователя (`%LOCALAPPDATA%\Throne\config` в Windows, `~/.config/Throne/config` в Linux). Если она не может записывать в собственную папку, например в `Program Files`, она сама переключается туда: один раз копирует существующую папку `config` и дальше использует папку пользователя, даже если запустить её от имени администратора.
- Пакеты из других источников (WinGet, Scoop, AUR, Nix) могут использовать другие папки. `Открыть папку конфигурации` всегда показывает нужную.
- Геофайлы Xray `geoip.dat` и `geosite.dat`, а также папка `diagnostics` (из `Основные настройки` (Basic Settings) → `Диагностика` (Diagnostics)) лежат рядом с папкой `config`, а не внутри неё.

### Файлы в папке конфигурации {#config-files}

| Файл или папка | Что содержит |
| --- | --- |
| `throne.db` | Профили, группы, профили маршрутизации, профили OTP и настройки (SQLite). Пока Throne работает, рядом с ним появляются `throne.db-wal` и `throne.db-shm`. |
| `throne_stats.db` | Историю трафика для `Утилиты` (Tools) → `Статистика трафика` (Traffic Stats): поминутно за 48 часов, почасово за 90 дней. `Основные настройки` → `Интерфейс` (Style) → `Отключить агрегацию трафика` (Disable Traffic Aggregation) отключает её сбор. |
| `cache.db` | Кэш ядра: загруженные наборы правил, последний выбор каждого профиля автовыбора и, если включён `Сохранять кэш в файл` (Save Cache To File), кэш DNS. |
| `logs/` | Файлы логов, см. [Файл лога](#log-file). |
| `crashes/` | Аварийные дампы (только Windows). Хранятся 5 самых новых. |
| `icons/` | Собственные значки трея для `Основные настройки` → `Интерфейс` → `Включить пользовательские иконки` (Enable Custom Icons): `Off.png`, `Throne.png` (запущен профиль), `Proxy.png`, `Tun.png` и `Connecting.png`. |
| `hwid` | Только Linux: идентификатор устройства, который Throne создал, потому что в системе нет пригодного `/etc/machine-id` или `/var/lib/dbus/machine-id`. См. [HWID](@/reference/privacy.ru.md#hwid). |
| `.lock` | Показывает, что эту папку использует Throne. Throne никогда не удаляет этот файл. |
| `dashboard/` | Веб-панель для Clash API. Замените страницу-заглушку файлами панели. |
| `sb-dashboard/` | Веб-панель, которую открывает `Утилиты` → `Открыть веб-панель` (Open Web dashboard). |

Чтобы перенести данные на другой компьютер или на Android, используйте резервную копию `.thrbackup`, а не копируйте файлы. См. [Резервное копирование и восстановление](@/guides/backup.ru.md#backup-restore).

## Логи {#logs}

Вкладка `Логи` (Logs) в нижней части главного окна показывает сообщения Throne и ядра.

Параметры логов находятся в `Настройки` → `Основные настройки` → `Логирование` (Logging) (только в расширенном режиме):

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Макс. кол-во строк в логах` (Max log lines) | `500` | Сколько строк хранит вкладка `Логи`. |
| `Уровень логирования Sing-box` (Sing-box Log level) | `info` | Насколько подробно пишет ядро: `trace`, `debug`, `info`, `warn`, `error`, `fatal` или `panic`. |
| `Уровень логирования Xray` (Xray Log level) | `warning` | Насколько подробно пишет Xray: `debug`, `info`, `warning`, `error` или `none`. |
| `Фильтрация логов` (Log Filtering) | Выкл. | `Использовать правила включения` (Enable Include Rules) показывает только строки, совпадающие с вашими ключевыми словами или регулярными выражениями, `Использовать правила исключения` (Enable Exclude Rules) скрывает их. Скрытые строки всё равно попадают в файл лога. |

Чтобы записать подробный лог для отчёта об ошибке, следуйте инструкциям на странице [Как сообщить об ошибке](@/help/bug_reports.ru.md#logs).

### Файл лога {#log-file}

Throne также записывает лог, более подробный, в файл `logs/throne.log` в папке конфигурации.

- Throne начинает новый файл при каждом запуске. Когда файл достигает 4 MB, Throne переименовывает его в `throne.log.1` и начинает новый; хранится до трёх старых частей (от `throne.log.1` до `throne.log.3`).
- Если Throne завершил работу некорректно, лог этого сеанса сохраняется как `crashed-YYYYMMDD-HHMMSS.log` (хранятся 5 самых новых), а при следующем запуске вкладка `Логи` показывает предупреждение с путём к папке логов.

{% alert_warning() %}
Логи могут содержать домены, которые вы посещали, и адреса ваших серверов. Проверьте лог, прежде чем публиковать его.
{% end %}

**Android:** откройте `Журналы` (Logs) в боковом меню. `Поделиться журналом` (Share logs) и `Сохранить журнал…` (Save logs…) экспортируют лог, по умолчанию скрывая конфиденциальные данные. Уровень логирования задаётся в `Настройки` (Settings) → `Ядро` (Core) → `Тип журнала` (Log level) (по умолчанию `warn`). См. [Устранение неполадок на Android](@/android/troubleshooting.ru.md#logs).

## Сброс Throne {#reset}

В Throne нет кнопки сброса. Чтобы начать заново с настройками по умолчанию, дайте Throne новую пустую папку конфигурации:

1. Если хотите что-то сохранить, сначала создайте резервную копию: `Настройки` → `Основные настройки` → `Резервное копирование и восстановление` (Backup and Restore) → `Создать резервную копию` (Create Backup...).
2. `Настройки` → `Открыть папку конфигурации` показывает, где находится папка.
3. Завершите работу Throne командой `Выход` (Exit) в меню трея или в меню `Программа`. Закрыть окно недостаточно.
4. Переименуйте папку `config`, например в `config-old`.
5. Запустите Throne. Он создаст новую папку `config` с настройками по умолчанию.

Чтобы вернуть часть старых данных, нажмите `Восстановить из копии` (Restore from Backup...) на той же вкладке и выберите только нужные части. Чтобы отменить сброс, завершите работу Throne, удалите новую папку `config` и переименуйте `config-old` обратно в `config`.

Сброс не затрагивает то, что хранится вне папки конфигурации: `Запускать вместе с системой` (Start with system) (запись автозапуска системы), регистрацию ссылок `throne://` и геофайлы Xray.

**Windows:** при удалении копии, установленной установщиком, программа предлагает удалить и папку конфигурации.

**Android:** `Настройки` (Settings) → `Восстановить настройки по умолчанию` (Restore default settings) сбрасывает все настройки, но сохраняет профили, группы и профили маршрутизации, после чего приложение перезапускается. Чтобы удалить всё, очистите данные приложения в настройках приложений Android. Файловые менеджеры не могут открыть данные приложения, поэтому, чтобы скопировать их наружу, используйте резервную копию `.thrbackup`.
