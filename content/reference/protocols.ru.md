На этой странице перечислены все типы профилей в Throne для компьютера и Throne для Android, ссылки и файлы, которые Throne может импортировать, а также способы поделиться профилем. С её помощью можно проверить, поддерживает ли Throne ваш сервер, прежде чем его импортировать.

## Типы профилей {#protocols}

Чтобы создать профиль вручную, выберите на компьютере `Программа` (Program) → `Новый профиль` (New profile) (`Ctrl+N`), а на Android — `Добавить профиль` (Add profile) → `Ручные настройки` (Manual settings), и укажите тип. Тип существующего профиля изменить нельзя. В простом режиме список на компьютере не предлагает `Напрямую` (Direct), `Цепочка прокси` (Chain Proxy), `Доп. ядро` (Extra Core) и пользовательские типы (Custom) — они есть только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode).

|---|---|---|---|

| `Socks` | Да | Да | SOCKS версии 5 или 4. |

Некоторые английские названия на Android отличаются только регистром букв, например `SOCKS` и `Auto selector`.

`AnyTLS`, `Hysteria`, `Juicity`, `MASQUE`, `ShadowTLS`, `TrustTunnel` и `TUIC` всегда используют TLS, поэтому в их редакторах нет переключателя, который выключает TLS. В Throne для Android до версии 2.0.3 включительно профиль такого типа, созданный вручную, при сохранении терял свои настройки TLS, например SNI. Начиная с 2.0.4, редакторы их сохраняют.

### Какой движок запускает профиль {#engines}

ThroneCore, ядро Throne, запускает все типы профилей с помощью sing-box, за двумя исключениями:

- `VLESS (Xray)`, `Пользовательский (Xray outbound)` и `Пользовательский (конфигурация Xray)` работают в движке Xray, встроенном в ядро.
- `Доп. ядро` запускает выбранную вами внешнюю программу.

Типы DNS-туннелей `DNSTT / VayDNS` и `MasterDNS` работают в sing-box. XDNS — это профиль `VLESS (Xray)`, поэтому он работает в Xray. См. [DNS-туннели](@/advanced/dns_tunnels.ru.md#how-it-works).

Throne для Android использует то же ядро, поэтому там действуют те же правила. Цепочка может сочетать оба движка, но только в таком порядке: звенья sing-box, затем звенья Xray, затем снова звенья sing-box.

Когда вы импортируете ссылку `vless://`, её тип определяет параметр `Настройки` (Settings) → `Основные настройки` (Basic Settings) → `Ядро` (Core) → `Предпочтение Xray для VLESS` (Xray VLESS Preference) (только в расширенном режиме). При значении по умолчанию, `XHTTP And Reality`, ссылки с XHTTP или REALITY становятся профилями `VLESS (Xray)`, а остальные — `VLESS`. Ссылки, которым нужна функция, доступная только в Xray (например, шифрование VLESS или, начиная с 1.4.0, транспорт mKCP — `type=kcp`), всегда становятся `VLESS (Xray)`. Начиная с 1.4.0, этому же параметру следуют записи VLESS с REALITY в YAML Clash. См. [sing-box или Xray](@/advanced/xray.ru.md#vless-preference).

## Форматы импорта {#import-formats}

### Где импортировать {#where-to-import}

| Источник | Компьютер | Android |
|---|---|---|
| Буфер обмена | `Ctrl+V` или `Программа` → `Добавить профиль из буфера обмена` (Add profile from clipboard) | `Добавить профиль` → `Импорт из буфера обмена` (Import from clipboard) |
| Файлы | `Программа` → `Добавить профиль из файла` (Add profile from File(s)) (`Ctrl+O`) или перетащите файлы в главное окно | `Добавить профиль` → `Импортировать из файла` (Import from file) |
| QR-коды | `Программа` → `Сканировать QR-код` (Scan QR Code) (`Ctrl+Shift+Q`) считывает QR-коды на ваших экранах. Изображения с QR-кодами тоже можно импортировать как файлы. | `Добавить профиль` → `Отсканировать QR-код` (Scan QR code) (камерой или через `Выбрать изображение` (Select image)) |
| Подписки | Группа типа `Подписка` (Subscription), см. [Подписки и группы](@/guides/subscriptions.ru.md#add-subscription) | То же самое, в разделе `Группы` (Groups) |
| Ссылки | Ссылки `throne://`, см. [Глубокие ссылки](@/advanced/deeplinks.ru.md) | Ссылки `throne://` и ссылки протоколов, которые вы открываете в других приложениях |

Импортированные профили попадают в текущую группу. Если в буфере обмена находится один URL `http://` или `https://`, Throne спрашивает, как его использовать: как новую группу подписки, для однократного импорта в текущую группу или как HTTP-прокси.

### Поддерживаемые форматы {#formats}

Throne для компьютера и Throne для Android понимают одни и те же форматы во вставленном тексте, файлах, QR-кодах и ответах подписок.

| Формат | Результат |
|---|---|
| Ссылки для обмена, по одной на строку: `vless://`, `vmess://`, `ss://`, `trojan://`, `socks://`, `socks4://`, `socks4a://`, `socks5://`, `http://`, `https://`, `hysteria://`, `hysteria2://`, `hy2://`, `tuic://`, `juicity://`, `anytls://`, `mieru://`, `mierus://`, `snell://`, `tt://` (TrustTunnel), `shadowtls://`, `wg://`, `wireguard://`, `awg://` (на компьютере, начиная с 1.4.0), `ssh://`, `naive+https://`, `naive+quic://` | По одному профилю на каждую ссылку |
| Ссылки Throne: `throne://add/…` и более старые `json://…` | Один профиль любого типа |
| Ссылки AmneziaVPN: `vpn://…` | Конфигурации, содержащиеся в ссылке |
| Ссылки DNS-туннелей: `dnst://`, `slipnet://`, `masterdns://`, `stormdns://` (на компьютере, начиная с 1.4.0) | По одному профилю `DNSTT / VayDNS` или `MasterDNS` на ссылку, см. [DNS-туннели](@/advanced/dns_tunnels.ru.md#import) |
| JSON sing-box: полная конфигурация или массив outbound | По одному профилю на каждый поддерживаемый outbound, на компьютере также `dnstt` и `masterdns` (начиная с 1.4.0) |
| JSON sing-box: один объект outbound | Один профиль `Пользовательский (sing-box outbound)` |
| JSON Xray: конфигурация, массив outbound или один outbound | `VLESS (Xray)` для outbound VLESS, `Пользовательский (Xray outbound)` для остальных |
| JSON Xray: массив полных конфигураций | По одному профилю `Пользовательский (конфигурация Xray)` на каждую конфигурацию |
| JSON SIP008 (Shadowsocks) | Профили `Shadowsocks` |
| YAML Clash или Mihomo со списком `proxies:` | Профили для записей `socks5`, `http`, `ss`, `vmess`, `vless`, `trojan`, `anytls`, `snell`, `hysteria`, `hysteria2`, `tuic`, `masque` и `ssh` |
| Файл `.conf` WireGuard или AmneziaWG | Один профиль `WireGuard`, названный по комментарию `# Name =` или `# remarks:` либо по комментарию над `[Peer]` (на компьютере начиная с 1.4.0, на Android начиная с 2.0.2) |
| Файл `.ovpn` OpenVPN | Один профиль `OpenVPN` |
| XML-профиль AnyConnect, командная строка `openconnect` или файл со строкой `protocol=` | Профили `OpenConnect` |
| Любой из перечисленных форматов в кодировке Base64 | Сначала декодируется, затем импортируется |

`tt://` охватывает оба вида ссылок TrustTunnel: `tt://user:password@server:port?…` и глубокую ссылку `tt://?…`, которую создают приложения TrustTunnel. Throne читает версию 1 такой глубокой ссылки, а начиная с 1.4.0 (на Android — начиная с 2.0.4) и версию 2. В ссылке должны быть адрес сервера, имя сервера, имя пользователя и пароль, поэтому ссылка, в которой есть только адрес подписки, отклоняется. Если в ссылке перечислено несколько адресов серверов, Throne импортирует первый и предупреждает об остальных.

Записи, которые не являются прокси-серверами, пропускаются, например outbound sing-box `direct`, `block`, `selector` и `urltest` или outbound Xray `freedom` и `blackhole`. Чтобы запустить полную конфигурацию sing-box или Xray, создайте профиль `Пользовательский (конфигурация sing-box)` (Custom (sing-box config)) или `Пользовательский (конфигурация Xray)` (Custom (Xray config)) и вставьте в него конфигурацию. См. [Полные конфигурации](@/advanced/chains.ru.md#full-configs).

Оба приложения отклоняют файлы для импорта размером больше 50 MB (на Android это ограничение не касается файлов `.zip`) и ответы подписок больше 64 MB.

### Значения, которые нельзя использовать {#unusable-values}

Начиная с 1.4.0 (на Android — начиная с 2.0.5), некоторые значения, которые Throne не может использовать, больше не останавливают импорт профиля. Throne пропускает такое значение, импортирует остальное и пишет предупреждение в [отчёт об изменениях](@/guides/subscriptions.ru.md#change-report):

- `flow`, который профиль `VLESS` или `VLESS (Xray)` не может использовать, например Vision на транспорте, который его не поддерживает.
- Неверная настройка XHTTP. Неверный режим XHTTP становится `auto`.
- Неверный `spx` (spider X) у REALITY.
- Неверный порт или диапазон портов Mieru.

В этих же версиях Throne также читает такие значения:

- `upmbps` и `downmbps` в ссылках Hysteria с единицей измерения, например `55Mbps`.
- Несколько записей `local_address` у WireGuard, разделённых запятыми.
- Пустое `encryption` в ссылках `VLESS (Xray)`, что означает `none`.

Начиная с 1.4.0, ссылка, JSON или запись Clash для Hysteria 2 с типом обфускации `none`, `plain` или пустым импортируется без обфускации. В редакторе тот же результат даёт `Obfuscation` → `Нет` (None).

### Отличия на Android {#android-import}

- URL подписки также может быть адресом `content://`, который указывает на файл на устройстве.
- `Импортировать из файла` (Import from file) принимает и файл `.zip` и импортирует все файлы внутри него, например несколько конфигураций WireGuard или OpenVPN.
- Ссылки, начинающиеся с `clash://install-config?url=…`, открывают Throne и добавляют URL как подписку.
- Если в другом приложении нажать на ссылку протокола (например, `vless://…`) или на ссылку `throne://`, Throne откроется и перед импортом профиля спросит подтверждение.
- Системное меню «Поделиться» в Android предлагает Throne только для двоичных файлов (`application/octet-stream`), например резервных копий. Чтобы импортировать ссылку из мессенджера, скопируйте её и выберите `Импорт из буфера обмена` (Import from clipboard). Для других файлов используйте `Импортировать из файла`.
- Профили `Tailscale`, `Доп. ядро` (Extra Core), `DNSTT / VayDNS` и `MasterDNS` на Android использовать нельзя, а ссылки DNS-туннелей он не импортирует.
- Начиная с 2.0.2, Throne для Android при импорте и обновлении пропускает записи, которые не может запустить его ядро, например XHTTP у профиля, отличного от VLESS. В логе каждая такая запись отмечена как `Skipped` с типом, названием и причиной.

## Ссылки для обмена {#share-links}

### Типы ссылок {#link-types}

| Ссылка | Как выглядит | Кто может её прочитать |
|---|---|---|
| Стандартная ссылка | `vless://…`, `ss://…`, `hysteria2://…` и так далее | Throne и большинство других клиентов |
| Ссылка Throne | `throne://add/…` | Throne для компьютера и Throne для Android |
| Старая ссылка Throne | `json://…` | Throne, только для импорта |

**Стандартная ссылка** использует обычный формат ссылок протокола. У некоторых типов стандартной ссылки нет: `Автовыбор` (Auto Selector), `Цепочка прокси` (Chain Proxy), типы `Пользовательский (…)` (Custom), `Напрямую` (Direct), `Доп. ядро` (Extra Core), `MASQUE`, `OpenVPN` и `OpenConnect`. Нет её и у профилей `VLESS (Xray)` с транспортом XDRIVE. Для них Throne выдаёт вместо неё ссылку Throne. Если у такого профиля заданы расширенные параметры подключения, например интерфейс для привязки, Throne вместо ссылки Throne показывает неполную ссылку, которая содержит только эти параметры. Для таких профилей отметьте `Deep Link` или выберите `Копировать ссылки выбранных (deep links)` (Copy links of selected (Deep Links)). Для `Tailscale` тоже передавайте ссылку Throne: Throne не может импортировать ссылку `ts://`, которую он показывает для таких профилей. Профили `DNSTT / VayDNS` и `MasterDNS` дают ссылку `dnst://`, см. [DNS-туннели](@/advanced/dns_tunnels.ru.md#import).

**Ссылка Throne** содержит настройки профиля в виде JSON, закодированного в Base64. Она работает для любого типа профиля, включая типы без стандартной ссылки, но прочитать её может только Throne. См. [Глубокие ссылки](@/advanced/deeplinks.ru.md#add). Ссылки `json://` — это формат ссылок Throne, который использовался до версии 1.2.0; Throne по-прежнему их импортирует.

Ссылка на профиль `Цепочка прокси` или `Автовыбор` хранит только внутренние номера профилей или группы, которые он использует, а не сами серверы. Она пригодна только в той же установке Throne.

### ECH и закреплённые сертификаты в ссылках {#ech-links}

Начиная с версии 1.4.0 для компьютера и 2.0.2 для Android, Throne читает и записывает в стандартных ссылках такие параметры TLS:

| Параметр | Значение |
|---|---|
| `ech=1` или `ech=true` | Включает ECH. Ядро ищет конфигурацию ECH в DNS. |
| `ech=` домен или домен, `+` и URL DNS-сервера | Включает ECH и указывает домен для поиска и при необходимости DNS-сервер для запроса, например `cloudflare-ech.com+https://1.1.1.1/dns-query`. Заполняет поле `ECH Query Name / Resolver`. |
| `ech=` любое другое значение | Включает ECH с этой конфигурацией ECH в Base64. |
| `pcs=` | Хеши SHA-256 сертификата сервера в шестнадцатеричном виде через запятую. Совпадающий сертификат принимается вместо обычной проверки по удостоверяющему центру. Заполняет поле `Certificate SHA256`. |

Для профилей `VLESS (Xray)` значение `ech` без изменений попадает в `ECH Config List`. Ссылки, которые создаёт Throne, также сохраняют старые параметры `ech_enabled`, `ech_config` и `ech_server_name`. О том, что делает ECH, см. [ECH](@/advanced/presets.ru.md#ech).

### Обмен на компьютере {#share-desktop}

Щёлкните профиль в списке правой кнопкой мыши и откройте `Поделиться` (Share):

| Действие | Что вы получаете |
|---|---|
| `QR-код и ссылка` (QR Code and link) | Окно со стандартной ссылкой и её QR-кодом. Отметьте `Deep Link`, чтобы вместо неё показать ссылку Throne. Типы без стандартной ссылки обычно открываются с уже отмеченным `Deep Link` (см. выше). |
| `Копировать ссылки выбранных` (Copy links of selected) (`Ctrl+C`) | Стандартные ссылки всех выбранных профилей, по одной на строку. Типы без стандартной ссылки обычно копируются как ссылки Throne (см. выше). |
| `Копировать ссылки выбранных (deep links)` (Copy links of selected (Deep Links)) (`Ctrl+Alt+C`) | Ссылки Throne всех выбранных профилей. |

Чтобы скопировать ссылки всей группы, откройте `Группы` (Groups) → `Редактировать текущую группу` (Edit current Group) и нажмите `Копировать ссылки профилей` (Copy profile share links) или `Копировать ссылки профилей (deep links)` (Copy profile share links (Deep Links)).

`Поделиться` → `Экспортировать конфиг` (Export config) (`Ctrl+E`) показывает конфигурацию ядра, которую Throne создаёт для профиля, на вкладке `sing-box` и, для профилей, использующих Xray, на вкладке `Xray`. `Копировать` (Copy) копирует открытую вкладку. Это файл конфигурации для других клиентов, а не ссылка для обмена. До версии 1.4.0 вместо этого были пункты `Экспортировать конфиг Sing-box` (Export Sing-box config) и `Экспортировать конфиг Xray` (Export Xray config).

В простом режиме пункты `Копировать ссылки выбранных (deep links)` и `Экспортировать конфиг` скрыты (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

Чтобы импортировать QR-код, показанный на экране, выберите `Программа` → `Сканировать QR-код` (`Ctrl+Shift+Q`). Чтобы импортировать QR-код из файла изображения, перетащите файл в главное окно или откройте его через `Программа` → `Добавить профиль из файла`.

### Обмен на Android {#share-android}

Нажмите кнопку «Поделиться» у профиля. У карточек в два столбца и, начиная с 2.0.5, у компактных строк (`Компактные строки профилей` (Compact profile rows)) этой кнопки нет: вместо неё нажмите ⋮ → `Поделиться` (Share) в строке профиля. Начиная с 2.0.5, макет `Два столбца` (Double column) доступен только в альбомной ориентации, кнопкой на панели инструментов. См. [Вид списка профилей](@/android/_index.ru.md#layout).

В меню есть:

- `QR-код` (QR code) → `Стандарт` (Standard) или `Ссылка Throne` (Throne link)
- `Экспорт в буфер обмена` (Export to clipboard) → `Стандарт` или `Ссылка Throne`
- `Конфигурация` (Configuration) → `Экспорт в буфер обмена` или `Экспорт в файл` (Export to file): конфигурация ядра, которую создаёт Throne, а не ссылка для обмена

Пункта `Стандарт` нет, если у типа профиля нет стандартной ссылки. Цепочками на Android поделиться нельзя. Чтобы скопировать ссылки всей группы, откройте `Группы` (Groups), нажмите `Другие параметры` (More options) у группы и выберите `Копировать ссылки для обмена профилями` (Copy profile share links) или `Копировать ссылки для обмена профилями (deep link)` (Copy profile share links (deep links)).

Чтобы импортировать полученный профиль, выберите `Добавить профиль` → `Отсканировать QR-код` или `Импорт из буфера обмена`. Ссылка Throne из буфера обмена или QR-кода импортируется без дополнительного вопроса.
