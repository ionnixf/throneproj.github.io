Сочетания клавиш работают, когда окно Throne активно. **macOS:** `Ctrl` означает `Cmd`, а `Alt` — `Option`, поэтому `Ctrl+Shift+S` — это `Cmd+Shift+S`. На клавиатуре ноутбука Mac клавиша `Del` — это `Fn+Delete`.

## Главное окно {#main-window}

В меню `Настройки` (Settings) и `Маршрутизация` (Routing) сочетаний клавиш нет. Столбец «Можно изменить» показывает, можно ли назначить другое сочетание, см. [Изменение сочетания клавиш](#change-shortcuts). Простой режим скрывает часть пунктов, например `Преобразовать домены группы в IP` (Resolve Domain for group), `Экспортировать конфиг` (Export config) и `Сбросить трафик` (Reset Traffic) (см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

В строке состояния щёлкните запущенный профиль, чтобы выполнить для него тест задержки, или `Mixed: …`, чтобы открыть `Основные настройки` (Basic Settings).

### Меню «Программа» {#program-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Скрыть окно` (Hide window) | `Ctrl+H` (macOS: также `Cmd+W`) | Да |
| `Новый профиль` (New profile) | `Ctrl+N` | Да |
| `Добавить профиль из буфера обмена` (Add profile from clipboard) | `Ctrl+V` | Нет |
| `Добавить профиль из файла` (Add profile from File(s)) | `Ctrl+O` | Да |
| `Сканировать QR-код` (Scan QR Code) | `Ctrl+Shift+Q` | Да |

Чтобы импортировать файлы, изображения с QR-кодом или ссылки, их также можно перетащить в окно.

### Меню «Группы» {#groups-menu}

Действия с группой применяются к группе открытой вкладки.

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Тест задержки всей группы` (Url Test Group) | `Ctrl+Shift+G` | Да |
| `Тест скорости всей группы` (Speedtest Group) | `Ctrl+Alt+P` | Да |
| `Преобразовать домены группы в IP` (Resolve Domain for group) | `Ctrl+Shift+I` | Да |
| `Очистить результат теста для группы` (Clear Group test result) | `Ctrl+Shift+C` | Да |
| `Обновить подписку` (Update subscription) | `Ctrl+U` | Да |
| `Очистка` (Clean up) → `Удалить дубликаты` (Remove Duplicates) | `Ctrl+Shift+D` | Да |
| `Очистка` → `Удалить недоступные` (Remove Unavailable) | `Ctrl+Shift+R` | Да |
| `Очистка` → `Удалить недействительные` (Remove Invalid) | `Ctrl+Alt+I` | Да |
| `Остановить тестирование` (Stop Testing) | `Ctrl+.` | Да |

`Остановить тестирование` появляется, только пока идёт тест. Щёлкните вкладку группы правой кнопкой мыши, чтобы открыть меню группы; перетаскивайте вкладки, чтобы изменить порядок групп.

### Меню «Утилиты» {#tools-menu}

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Search Settings` | `Ctrl+K` | Да |
| `Тест скорости текущего профиля` (Speedtest Current) | `F6` | Да |

`Search Settings` открывает [палитру команд](#command-palette). `Тест скорости текущего профиля` работает, только когда профиль запущен.

## Палитра команд {#command-palette}

Палитра команд находит команды меню и параметры по названию. Нажмите `Ctrl+K` в главном окне или выберите `Утилиты` (Tools) → `Search Settings`.

- Введите одно или несколько слов. Пункт подходит, если все слова есть в его названии или пути, например `Основные настройки › Общие › Настройки inbound`. В переведённом интерфейсе многие пункты находятся и по английским словам.
- Начните запрос с `>`, чтобы искать только команды, или с `@`, чтобы искать только параметры. Один символ `@` показывает все параметры.
- Нажмите `Enter` или дважды щёлкните пункт, чтобы выполнить его. `Esc` закрывает палитру.

Палитра находит параметры окон `Основные настройки` (Basic Settings), `Настройки маршрутизации` (Routing Settings), `Настройки режима TUN` (Tun Settings), `Предустановленные настройки` (Preset Settings) и `Настройки интеграции` (Integration Settings), а также команды, которые меню показывают в данный момент, включая меню списка профилей и ваши профили маршрутизации.

В простом режиме палитра находит и скрытые параметры — под заголовком `Настройки в расширенном режиме` (Settings in Advanced mode); если выбрать такой параметр, Throne переключится в расширенный режим. Скрытые команды меню не показываются.

Одновременно может быть открыто только одно из этих окон: окно настроек, `Управление группами` (Manage Groups), `Менеджер OTP` (OTP Manager), `Статистика трафика` (Traffic Stats) и `О программе` (About). Пока одно из них открыто, палитра затеняет пункты, которые открыли бы другое окно.

## Список профилей {#profile-list}

Щёлкните список профилей правой кнопкой мыши, чтобы открыть его меню. Кроме действий добавления из меню `Программа`, в нём есть:

| Действие | Сочетание клавиш | Можно изменить |
| --- | --- | --- |
| `Запустить` (Start) | `Enter` | Нет |
| `Остановить` (Stop) | `Ctrl+S` | Нет |
| `Поделиться` (Share) → `Экспортировать конфиг` (Export config) | `Ctrl+E` | Да |
| `Поделиться` → `Копировать ссылки выбранных` (Copy links of selected) | `Ctrl+C` | Нет |
| `Поделиться` → `Копировать ссылки выбранных (deep links)` (Copy links of selected (Deep Links)) | `Ctrl+Alt+C` | Нет |
| `Удалить` (Delete) | `Del` | Нет |
| `Выбрать все` (Select All) | `Ctrl+A` | Нет |
| `Дублировать` (Clone) | `Ctrl+D` | Да |
| `Тест задержки` (Url Test Selected) | `Ctrl+Shift+S` | Да |
| `Тест скорости` (Speedtest Selected) | `Ctrl+Shift+P` | Да |
| `Сбросить трафик` (Reset Traffic) | `Ctrl+R` | Да |

Другие клавиши и действия мышью в списке:

| Клавиша или действие | Что происходит |
| --- | --- |
| Двойной щелчок по профилю | Открывает редактор профиля. |
| `Esc` | Снимает выделение. В строке фильтра закрывает строку фильтра. |
| Перетаскивание строки | Перемещает профиль. Не работает, пока активен фильтр. |
| `Ctrl+F` | Показывает или скрывает строку фильтра. При скрытии фильтры сбрасываются. |
| `Up` в первой строке, `Down` в строке фильтра | Переход между списком и строкой фильтра. |

### Действия без сочетания по умолчанию {#no-default}

Сочетание клавиш можно назначить действиям `QR-код и ссылка` (QR Code and link), `Копировать результат теста` (Copy Test Result), `Преобразовать выбранный домен в IP` (Resolve Selected Domain), `Определить выходной IP выбранных` (Resolve Selected Out IP), `Очистить результат теста` (Clear Test Result), `Определить выходной IP группы` (Resolve out IP for group), `Обновить все подписки` (Update all subscriptions), `Удалить небезопасные конфигурации` (Remove Insecure Configs), `IP-сканер` (IP Scanner) и `Обновить ширину колонок` (Refresh Column Widths).

## Изменение сочетания клавиш {#change-shortcuts}

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings) → `Сочетания клавиш` (Shortcuts) (только в расширенном режиме, см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).
2. Щёлкните поле рядом с действием и нажмите новое сочетание клавиш. `Backspace` удаляет сочетание.
3. Нажмите `ОК` (OK).

Сочетания, отмеченные выше как «Нет», и `Ctrl+F` изменить нельзя. Если сочетание уже использует другое действие или глобальная горячая клавиша, окно называет конфликт и не сохраняет изменения, пока вы не измените одно из сочетаний.

## Глобальные горячие клавиши {#global-hotkeys}

Глобальные горячие клавиши работают в любом приложении, даже когда окно Throne скрыто. По умолчанию ни одна из них не задана.

1. Откройте `Настройки` → `Настройки интеграции` (Integration Settings) → `Глобальные горячие клавиши` (Global Hotkeys).
2. Щёлкните поле горячей клавиши и нажмите сочетание клавиш.
3. Нажмите `ОК`.

| Горячая клавиша | Что делает |
| --- | --- |
| `Показать/скрыть главное окно` (Trigger main window) | Показывает главное окно или скрывает его, если оно активно, как щелчок по значку в трее. |
| `Показать группы` (Show groups) | Открывает `Управление группами` (Manage Groups). |
| `Показать маршруты` (Show routes) | Открывает `Настройки маршрутизации` (Routing Settings). |
| `Режим прокси` (Proxy mode) | Открывает у указателя мыши меню `Режим работы` (Operation Mode) с пунктами `Системный прокси` (System Proxy) и `Режим TUN` (Tun Mode). |
| `Вкл./выкл. системный прокси` (Toggle System Proxy) | Включает или выключает `Системный прокси`. |
| `Запустить/остановить профиль` (Start/Stop Profile) | Останавливает запущенный профиль или запускает последний профиль, если ни один не запущен. |
| `Вкл./выкл. режим TUN` (Toggle Tun Mode) | Включает или выключает `Режим TUN`. |

- В горячей клавише должна быть клавиша `Ctrl`, `Alt` или `Meta` (`Cmd` в macOS), если только это не функциональная клавиша, например `F9`.
- Сочетание, которое уже занято другой программой или системой, не работает. После нажатия `ОК` Throne перечисляет горячие клавиши, которые не удалось зарегистрировать.
- Пока открыто окно `Настройки интеграции`, глобальные горячие клавиши не действуют.
- **Linux:** глобальные горячие клавиши работают в сеансах X11 и KDE Plasma Wayland (в KDE Plasma они также отображаются в системных настройках сочетаний клавиш, в разделе `Throne`), но не в других сеансах Wayland.

Чтобы управлять Throne с макропада, Stream Deck или из скрипта, используйте [thronectl](@/advanced/api.ru.md#example-hotkey).

## Значок в трее {#tray}

Throne показывает значок в системном трее (в macOS — в строке меню). Значок меняется, пока запущен профиль и когда включён `Системный прокси` или `Режим TUN`. Наведите на него указатель, чтобы увидеть запущенный профиль и режим.

- **Windows и Linux:** щёлкните значок, чтобы показать или скрыть окно. Щёлкните его правой кнопкой мыши, чтобы открыть меню трея.
- **macOS:** щёлкните значок, чтобы открыть меню трея.

Закрытие окна не завершает работу Throne: он продолжает работать в трее. Чтобы выйти, выберите `Выход` (Exit) в меню трея или в меню `Программа`.

**macOS:** пока окно скрыто, значка Throne в Dock нет. Если Throne закреплён в Dock, щёлкните его значок в Dock или снова откройте Throne из Finder, чтобы показать окно.

**Linux:** GNOME показывает значки в трее, только если установлено расширение AppIndicator ([#1623](https://github.com/throneproj/Throne/issues/1623)). Без значка в трее запустите Throne ещё раз, чтобы вернуть его скрытое окно.

### Меню трея {#tray-menu}

| Пункт | Что делает |
| --- | --- |
| `Подключиться` (Connect) / `Отключиться` (Disconnect) | Останавливает запущенный профиль или запускает профиль, выбранный в списке; если ничего не выбрано — последний профиль, а если его нет — первый профиль открытой группы. |
| `Запоминать последний профиль` (Remember last profile) | При следующем запуске Throne снова запускает профиль, который работал при выходе, и снова включает `Системный прокси` и `Режим TUN`, если они были включены. Профиль, который вы остановили сами, не запоминается. |
| `Разрешить подключаться другим устройствам` (Allow other devices to connect) | Открывает локальный порт прокси для вашей сети, см. [Доступ из локальной сети](@/guides/proxy_modes.ru.md#lan-sharing). |
| `Выбор профиля` (Select Profile) | Запускает профиль, выбранный по группе или найденный по названию. |
| `Выбор маршрутизации` (Select Routing) | Делает профиль маршрутизации активным и перезапускает запущенный профиль. |
| `Коды OTP` (OTP Codes) | Щёлкните профиль OTP, чтобы скопировать его текущий код. В простом режиме скрыт. |

`Запускать вместе с системой` (Start with system) запускает Throne при входе в систему. Для этого Throne добавляет задание в Планировщик заданий в Windows, объект входа в macOS и файл `Throne.desktop` с параметром `-tray` в `~/.config/autostart` в Linux. В Windows и macOS окно открывается при входе в систему, если не включён параметр `Запускать приложение свёрнутым` (Hide dashboard at startup). В Windows при каждом запуске Throne настраивает задание на те же права, с которыми запущен сам: если Throne работает от имени администратора, задание тоже запускает его от имени администратора, если только не включён параметр `Всегда запускать Throne от имени обычного пользователя` (Always Start as Standard User).

### Настройки трея {#tray-settings}

В `Настройки` → `Основные настройки` → `Интерфейс` (Style):

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Запускать приложение свёрнутым` (Hide dashboard at startup) | Выкл. | Throne запускается только со значком в трее, как с параметром командной строки `-tray`. |
| `Откл. сворачивание в трей` (Disable tray) | Выкл. | Убирает значок из трея. После этого закрытие окна завершает работу Throne. |

{% alert_warning() %}
Не включайте `Откл. сворачивание в трей` вместе с `Запускать приложение свёрнутым` или `-tray`: Throne запустится без окна и без значка в трее. Если это произошло, запустите Throne ещё раз, и уже запущенный Throne покажет своё окно.
{% end %}
