## Где это теперь? {#where-did-it-go}

| В Nekoray / NekoBox вы использовали… | В Throne используйте… |
| --- | --- |
| Меню `Сервер` (Server) | Щелчок правой кнопкой мыши по списку профилей. |
| Меню `Настройки` (Preferences) | Кнопку `Настройки` (Settings) на панели инструментов. |
| `Настройки TUN-режима` (Tun Settings) → `Пропускать процессы` (Bypass Process Name) | Правила `processName:` в поле `Напрямую` (Direct) вашего профиля маршрутизации, например `processName:game.exe`. |
| `Настройки TUN-режима` → `Режим белого списка` (Whitelist mode) | Профиль маршрутизации, в котором для `Outbound по умолчанию` (Default outbound) выбрано `direct`, а программы или сайты указаны в поле `Прокси` (Proxy). |
| `Настройки TUN-режима` → `Пропускать CIDR` (Bypass CIDR) | `Настройки режима TUN` → `Обход частных диапазонов` (Private Range Bypass) или правила `ip:` в поле `Напрямую`. |
| `Пресет` (Preset) маршрутизации для вашей страны | `Маршрутизация` (Routing) → `Скачать профили` (Download Profiles). |
| `Outbound по-умолчанию` (Default Outbound) со значением `bypass` | `Outbound по умолчанию` со значением `direct` в профиле маршрутизации. |
| Темы вроде FlatGray, LightBlue и BlackSoft | `Основные настройки` (Basic Settings) → `Интерфейс` (Style) → `Тема` (Theme). |
| `Скопировать ссылки для выбранных (Neko links)` (Copy links of selected (Neko Links)) | Стандартные ссылки для обмена. Throne не умеет читать ссылки `nekoray://` и `sn://`. |
| `Перехват` (Hijack) или `Системный DNS` (System DNS) (Throne 1.3.2 и более ранние версии) | `Режим TUN` (Tun Mode). |
| NekoBox for Android | Throne для Android; см. [ниже](#from-nekobox-android). |

Простой режим скрывает часть этих пунктов; см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode). Для маршрутизации по приложениям включите `Режим TUN` (Tun Mode): трафик приложений, которые игнорируют системный прокси, никогда не доходит до Throne. См. [Маршрутизация](@/guides/routing.ru.md#simple-rules).

## Перенос данных {#moving-data}

### Из Nekoray {#from-nekoray}

Throne не умеет читать конфигурацию Nekoray. Перенесите данные вручную:

1. В Nekoray скопируйте URL каждой подписки из настроек её группы. В Throne нажмите `Ctrl+V` и выберите `Создать новую группу подписки` (Create new subscription group).
2. Выделите в Nekoray серверы, которые вы добавляли вручную, выберите `Сервер` (Server) → `Поделиться` (Share) → `Скопировать ссылки для выбранных` (Copy links of selected) и нажмите `Ctrl+V` в Throne.
3. Заново настройте маршрутизацию ([Маршрутизация](@/guides/routing.ru.md)) и параметры, которые вы меняли, например прослушиваемый порт, DNS-серверы и горячие клавиши.

Не запускайте Nekoray и Throne одновременно с включённым режимом TUN или системным прокси.

### Из Throne 1.0.x {#from-1-0}

В Throne 1.1.0 JSON-файлы в стиле Nekoray заменены базой данных (`throne.db`), и читать старые файлы новая версия не умеет: после обновления 1.0.x поверх старой установки ваши профили, группы и настройки не появятся ([#1765](https://github.com/throneproj/Throne/issues/1765)). Сохраните копию старой папки и перенесите данные вручную, как описано выше; в [#1202](https://github.com/throneproj/Throne/issues/1202) описаны шаги для ручного переноса и приведён неофициальный скрипт от сообщества. Между более новыми версиями используйте `Основные настройки` (Basic Settings) → `Резервное копирование и восстановление` (Backup and Restore) ([Резервное копирование, обновление и перенос](@/guides/backup.ru.md#backup-restore)).

### Из NekoBox for Android {#from-nekobox-android}

Throne для Android 2.0.0, который раньше назывался NekoBox for Android, заново построен на ядре версии для компьютера и не может обновить более старую версию:

- Он подписан новым ключом, поэтому сначала удалите старую версию.
- Он восстанавливает только файлы `.thrbackup`, включая резервные копии с компьютера, но не файлы резервных копий и `.zip`-файлы WebDAV версий 1.6.x и более ранних.

Перед удалением скопируйте URL своих подписок и ссылки для обмена серверов, которые вы добавляли вручную, или вместо этого восстановите на телефоне резервную копию с компьютера ([Резервное копирование, обновление и перенос](@/guides/backup.ru.md#desktop-android)). Подробности: [Установка и обновление](@/android/installation.ru.md#upgrading).
