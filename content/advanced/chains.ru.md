Цепочки, пользовательские конфигурации, дополнительное ядро (Extra Core), а также фронт-прокси и выходной прокси групп доступны только в расширенном режиме (см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)).

## Цепочки прокси {#chains}

Профиль-цепочка пропускает трафик через несколько профилей по очереди, сверху вниз: если сверху `A`, а под ним `B`, трафик идёт так: ваше устройство → `A` → `B` → интернет. Каждый сервер видит только предыдущий, а сайты видят нижний профиль.

### Создание цепочки {#create-chain}

1. Откройте `Программа` (Program) → `Новый профиль` (New profile) (`Ctrl+N`), установите `Тип` (Type) в значение `Цепочка прокси` (Chain Proxy) и введите `Название` (Name).
2. Нажмите `Выбор профиля` (Select Profile) и дважды щёлкните следующее звено в главном окне. Повторите для каждого звена.
3. Перетаскиванием расставьте строки в нужном порядке и нажмите `OK`.

### Ограничения {#chain-limits}

- Цепочка не может содержать другую цепочку или профиль автовыбора. Автовыбор, в свою очередь, пропускает цепочки.
- Профили `Пользовательский (конфигурация sing-box)` (Custom (sing-box config)) не могут быть звеньями. Профили `Пользовательский (sing-box outbound)` (Custom (sing-box outbound)) и `Пользовательский (Xray outbound)` (Custom (Xray outbound)) — могут.
- Цепочка может содержать один профиль `Доп. ядро` (Extra Core) или один профиль `Пользовательский (конфигурация Xray)` (Custom (Xray config)), и он должен быть верхним звеном. Звено `Пользовательский (конфигурация Xray)` нельзя сочетать с другими звеньями Xray.
- Все звенья Xray должны идти подряд, см. [Xray в цепочках](@/advanced/xray.ru.md#xray-in-chains).
- Тесты задержки (URL test) пропускают цепочки со звеном `Доп. ядро` или `Пользовательский (конфигурация Xray)`.
- Цепочка может быть outbound правила маршрутизации, если в ней нет звена `Доп. ядро` или звена с полной конфигурацией.
- Если звено было удалено, цепочка не запустится, пока вы не уберёте это звено.

## Фронт-прокси и выходной прокси {#front-landing}

Группа может добавить одно звено перед каждым своим профилем и одно после него: ваше устройство → `Фронт-прокси` (Front Proxy) → запущенный вами профиль → `Выходной прокси` (Landing Proxy) → WARP (если включён) → интернет. Фронт-прокси помогает, когда серверы группы доступны только через другой сервер; выходной прокси даёт всей группе один и тот же выход.

Чтобы их задать, щёлкните правой кнопкой мыши по вкладке группы → `Редактировать выбранную группу` (Edit selected Group). Действуют ограничения цепочек: ни один из них не может быть цепочкой, а в группе с фронт-прокси нельзя запустить профиль `Доп. ядро` или `Пользовательский (конфигурация Xray)`. Если один из них был удалён, профили группы не запустятся, пока вы его не замените. См. также [Подписки и группы](@/guides/subscriptions.ru.md#front-landing-proxy).

## Пользовательские конфигурации {#custom-config}

Пользовательский профиль содержит JSON для ядра в исходном виде — для параметров, которых нет в обычных редакторах. В `Программа` → `Новый профиль` есть четыре типа:

- `Пользовательский (sing-box outbound)`: один outbound или endpoint sing-box.
- `Пользовательский (конфигурация sing-box)`: полная конфигурация sing-box.
- `Пользовательский (Xray outbound)`: один outbound Xray.
- `Пользовательский (конфигурация Xray)`: полная конфигурация Xray.

`Редактор JSON` (Json Editor) проверяет JSON sing-box по схеме. Чтобы начать с JSON, который Throne генерирует для рабочего профиля или цепочки, щёлкните по нему правой кнопкой мыши → `Поделиться` (Share) → `Экспортировать конфиг` (Export config). Минимальный профиль `Пользовательский (sing-box outbound)`:

```json
{
  "type": "socks",
  "server": "203.0.113.10",
  "server_port": 1080
}
```

Импортированный JSON превращается в обычные профили (см. [Форматы импорта](@/reference/protocols.ru.md#import-formats)), но никогда в `Пользовательский (конфигурация sing-box)`. Этот тип создаётся только вручную.

### Полные конфигурации {#full-configs}

- **`Пользовательский (конфигурация sing-box)`** запускается точно в том виде, в каком написан. Throne не добавляет свои inbound, TUN, профиль маршрутизации, настройки DNS, WARP, фронт-прокси и выходной прокси, поэтому inbound должны быть в самой конфигурации.
- **`Пользовательский (конфигурация Xray)`** получает локальный SOCKS-inbound, перед которым стоит sing-box, поэтому режим TUN, профиль маршрутизации и настройки DNS продолжают действовать. Внутри Xray outbound выбирает раздел `routing` вашей конфигурации.

Полные конфигурации не могут быть outbound правила маршрутизации или конечной точкой профиля маршрутизации. Автовыбор может использовать профили `Пользовательский (конфигурация Xray)`, но пропускает `Пользовательский (конфигурация sing-box)`.

## Дополнительное ядро (Extra Core) {#extra-core}

Профиль `Доп. ядро` запускает на вашем компьютере другую прокси-программу — для протокола, который Throne не поддерживает. Программа должна открыть локальный SOCKS-сервер, к которому подключается Throne. Создайте профиль через `Программа` → `Новый профиль` → `Тип` `Доп. ядро`:

| Поле | Назначение |
| --- | --- |
| `Путь к ядру` (Core path) | Запускаемая программа. |
| `Аргументы` (Args) | Аргументы командной строки. `%s` заменяется путём к временному файлу с текстом из поля `Конфигурация` (Config). Значения с пробелами заключайте в кавычки, как в командной оболочке. |
| `Конфигурация` | Содержимое конфигурационного файла программы. Программа получает его, только если в поле `Аргументы` есть `%s`. |
| `Адрес SOCKS` (Socks address), `Порт SOCKS` (Socks port) | SOCKS-сервер программы (по умолчанию `127.0.0.1`). Порт должен совпадать с конфигурацией программы и отличаться от порта, который прослушивает сам Throne. |
| `Без логов` (No logs) | Скрывает вывод программы на вкладке `Логи` (Logs). |

Например, если программа читает конфигурацию через `-c <file>`, укажите в поле `Аргументы` значение `-c %s` и вставьте конфигурацию в поле `Конфигурация`.

Программа запускается и останавливается вместе с профилем; если она завершится сама, Throne остановит профиль. Она работает с обычными правами пользователя, даже если ядро Throne имеет права администратора или root для режима TUN. Профиль `Доп. ядро` не может быть outbound правила маршрутизации, а тесты задержки и автовыбор его пропускают.

## Android {#android}

- Цепочки: `Добавить профиль` (Add profile) → `Ручные настройки` (Manual settings) → `Прокси-цепочка` (Proxy chain), с тем же порядком звеньев и теми же ограничениями.
- У групп есть те же параметры `Фронтовый прокси` (Front proxy) и `Посадочный прокси` (Landing proxy).
- У профиля `Пользовательская конфигурация` (Custom config) те же четыре типа, они выбираются в `Config type`.
- Дополнительное ядро есть только в версии для компьютера. Android сохраняет такие профили из резервной копии с компьютера, но запустить их не может.
