Системный прокси и режим TUN работают, только пока запущен профиль. В это время Throne также слушает смешанный порт (mixed port), по умолчанию `127.0.0.1:2080`, для SOCKS- и HTTP-прокси-подключений.

Когда ни один профиль не запущен или приложение обходит системный прокси, его трафик идёт через ваше обычное подключение. Чтобы вместо этого блокировать такой трафик, включите [kill switch](@/advanced/kill_switch.ru.md).

## Системный прокси {#system-proxy}

Установите флажок `Системный прокси` (System Proxy) в главном окне или выберите `Режим работы` (Operation Mode) → `Системный прокси` в меню трея. Пока профиль запущен, Throne указывает смешанный порт в настройках прокси вашей системы. Права администратора не нужны.

Системный прокси используют только приложения, которые учитывают системные настройки прокси, например большинство браузеров. Остальные подключаются напрямую, например Discord, звонки в Telegram, терминалы, приложения из Microsoft Store (UWP) и многие игры.

- **Windows:** Throne записывает настройку прокси Windows; её вид задаёт `Формат прокси` (Proxy Format) в [настройках входящих подключений](#inbound-settings).
- **Linux:** поддерживаются только GNOME и KDE. Запускайте Throne от имени обычного пользователя, а не root, иначе он не сможет изменить эту настройку.
- **macOS:** Throne задаёт HTTP-, HTTPS- и SOCKS-прокси для каждой включённой сетевой службы.

Многие утилиты командной строки игнорируют системный прокси, но читают `HTTP_PROXY` и `HTTPS_PROXY`:

```bash
export HTTP_PROXY=http://127.0.0.1:2080 HTTPS_PROXY=http://127.0.0.1:2080
```

```powershell
$env:HTTP_PROXY = "http://127.0.0.1:2080"; $env:HTTPS_PROXY = "http://127.0.0.1:2080"
```

- Если процесс Throne принудительно завершён или аварийно закрылся, пока запущен профиль, настройка остаётся, и ваши приложения не могут подключиться. См. [FAQ](@/help/faq.ru.md#force-quit).
- Пока установлен флажок `Системный прокси`, собственные запросы Throne, например обновления подписок, тоже идут через смешанный порт.

## Режим TUN {#tun-mode}

Установите флажок `Режим TUN` (Tun Mode) в главном окне или выберите `Режим работы` → `Режим TUN` в меню трея. Тогда Throne направляет трафик всего компьютера, включая DNS, через виртуальный сетевой адаптер. Для этого нужны права администратора или root; см. [Режим TUN](@/guides/tun_mode.ru.md).

## Какой режим выбрать {#which-mode}

| | Системный прокси | Режим TUN |
| --- | --- | --- |
| Какие приложения охватываются | Только приложения, которые учитывают системный прокси | Все приложения |
| DNS | Приложения по-прежнему могут использовать ваш обычный DNS-сервер | Обрабатывается согласно [настройкам DNS](@/guides/dns.ru.md#how-dns-works) в Throne |
| Правила для приложений (`processName:`, `processPath:`) | Действуют только на приложения, которые используют прокси | Работают для всех приложений |
| Типичные проблемы | Приложения, игнорирующие прокси | Брандмауэры, антивирусы или другие VPN, блокирующие адаптер |

Для браузера достаточно системного прокси. Для приложений, которые его игнорируют, для звонков и игр, а также для правил для отдельных приложений используйте режим TUN (см. [Рецепты](@/guides/recipes.ru.md#calls-and-games)). Можно включить и оба режима: тогда приложения, учитывающие системный прокси, используют смешанный порт, а режим TUN перехватывает остальное.

Если включён параметр `Программа` (Program) → `Запоминать последний профиль` (Remember last profile), Throne при старте запускает последний профиль и снова включает `Системный прокси` и `Режим TUN`, если они были включены, когда вы вышли из программы.

## Общий доступ к прокси для других устройств {#lan-sharing}

Другие устройства в вашей сети, например телефоны, телевизоры или игровые приставки, могут использовать Throne на вашем компьютере в качестве прокси.

1. Выберите `Программа` → `Разрешить подключаться другим устройствам` (Allow other devices to connect) и перезапустите запущенный профиль.
2. Найдите адрес и порт компьютера в строке состояния, например `Mixed: 192.168.1.20:2080`.
3. Разрешите входящие подключения к этому порту в брандмауэре: в Windows разрешите `ThroneCore`, когда брандмауэр Windows спросит (или позже в `Разрешить работу с приложением через брандмауэр` (Allow an app through firewall)); в Linux, например, `sudo ufw allow 2080`; в macOS разрешите, когда macOS спросит.
4. На другом устройстве укажите SOCKS5- или HTTP-прокси с этим адресом и портом.

{% alert_warning() %}
Без пароля вашим прокси может воспользоваться любой пользователь вашей сети. Установите флажок `Включить авторизацию` (Enable Authorization) в [настройках входящих подключений](#inbound-settings), задайте `Имя пользователя для inbound` (Inbound Username) и `Пароль для inbound` (Inbound Password) и введите их на других устройствах.
{% end %}

Другие устройства, например роутер, могут также пользоваться [DNS-сервером](@/guides/dns.ru.md#dns-server) Throne. Чтобы раздать всё подключение через точку доступа Wi-Fi, см. [Рецепты](@/guides/recipes.ru.md#hotspot).

## Настройки входящих подключений {#inbound-settings}

Эти параметры управляют смешанным портом: `Настройки` (Settings) → `Основные настройки` (Basic Settings) → `Общие` (Common) → `Настройки inbound` (Inbound Settings). В простом режиме показан только `Прослушиваемый порт` (Listen Port) (см. [Простой и расширенный режим](@/get_started/configuration.ru.md#interface-mode)). Чтобы применить изменения, перезапустите запущенный профиль.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `Прослушиваемый адрес` (Listen Address) | `127.0.0.1` | `127.0.0.1` принимает подключения только от приложений на этом компьютере; `::` или `0.0.0.0` — также от других устройств. `Разрешить подключаться другим устройствам` устанавливает `::`. |
| `Прослушиваемый порт` (Listen Port) | `2080` | Смешанный порт для SOCKS (4, 4a и 5) и HTTP. |
| `Случайный порт` (Random port) | выкл. | Выбирает свободный порт при каждом запуске; он отображается в строке состояния. |
| `Включить авторизацию` (Enable Authorization) | выкл. | Требует `Имя пользователя для inbound` и `Пароль для inbound`. |
| `Отключить mixed inbound` (Disable Mixed Inbound) | выкл. | Отключает смешанный порт. `Системный прокси` тогда нельзя включить, а `Использовать прокси` (Use proxy) для собственных запросов Throne работает только в режиме TUN. |
| `Польз. inbound` (Custom Inbound) | пусто | Дополнительные входящие подключения (inbound) sing-box: JSON-объект со списком `inbounds`. |
| `Формат прокси` (Proxy Format) | `{ip}:{port}` | Только Windows. `{ip}:{port}` или `http://{ip}:{port}` объявляет HTTP-прокси, `socks={ip}:{port}` — SOCKS-прокси. |

## На Android {#android}

В Throne для Android есть режим `VPN`, который работает как режим TUN и используется по умолчанию, и режим `Только прокси` (Proxy only). См. [Режимы VPN и прокси](@/android/modes.ru.md).
