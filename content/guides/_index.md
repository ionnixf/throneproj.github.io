These guides cover the everyday features of Throne desktop. Throne for Android uses the same settings; where it differs, the guide says so. Android-only topics are in [Throne for Android](@/android/_index.md).

A new installation starts in Simple mode, which hides some of the options described here. See [Simple and Advanced mode](@/get_started/configuration.md#interface-mode).

New to Throne? Start with [Subscriptions & Groups](@/guides/subscriptions.md), [System Proxy, TUN & LAN Sharing](@/guides/proxy_modes.md) and [Routing](@/guides/routing.md).
