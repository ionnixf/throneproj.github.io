Throne برای Android (با نام پیشین NekoBox for Android) همان هستهٔ Throne دسکتاپ را اجرا می‌کند؛ بنابراین گروه‌ها، اشتراک‌ها، نمایه‌های مسیریابی، DNS، پیش‌تنظیم‌ها (presets)، انتخابگر خودکار (auto selector)، WARP و پشتیبان‌ها در هر دو برنامه به یک شکل کار می‌کنند. راهنماها این ویژگی‌ها را توضیح می‌دهند: [اشتراک‌ها و گروه‌ها](@/guides/subscriptions.fa.md)، [مسیریابی](@/guides/routing.fa.md)، [DNS](@/guides/dns.fa.md)، [تست و انتخابگر خودکار](@/guides/testing.fa.md)، [Cloudflare WARP](@/advanced/warp.fa.md) و [جابه‌جایی بین دسکتاپ و Android](@/guides/backup.fa.md#desktop-android). این بخش به موضوعاتی می‌پردازد که مخصوص Android هستند.

## راه‌اندازی سریع {#quick-start}

1. فایل APK مناسب دستگاه خود را نصب کنید. بیشتر گوشی‌ها به `arm64-v8a` نیاز دارند. [انتخاب APK مناسب](@/android/installation.fa.md#choose-apk) را ببینید.
2. Throne را باز کنید. اجازهٔ نمایش اعلان‌ها را بدهید و وقتی Throne دربارهٔ اجرا در پس‌زمینه سؤال کرد، روی `اجازه بده` (Allow) بزنید. [مجوزها و اجرا در پس‌زمینه](@/android/permissions.fa.md) را ببینید.
3. نشانی (URL) اشتراک خود را کپی کنید. در صفحهٔ `پیکربندی` (Profiles)، روی `اضافه‌کردن پراکسی جدید` (Add profile) (نماد صفحه با علامت به‌علاوه) ← `وارد کردن از بریده‌دان` (Import from clipboard) بزنید، یا برای کد QR، `اسکن از کد QR` (Scan QR code) را انتخاب کنید.
4. روی `ایجاد گروه اشتراک جدید` (Create new subscription group) بزنید. Throne گروه را اضافه می‌کند و نمایه‌های آن را دانلود می‌کند.
5. زبانهٔ گروه جدید را باز کنید و روی ⋮ ← `آزمایش` (Test) ← `آزمایش URL` (URL test) بزنید. وقتی تست تمام شد، روی `انتخاب سریع‌ترین` (Select fastest) بزنید، یا روی نمایه‌ای بزنید که کار می‌کند.
6. دکمهٔ گرد اتصال را در پایین صفحه بزنید و به درخواست VPN اجازه دهید.
7. برای بررسی اتصال، روی نوار پایین صفحه بزنید. «HTTP: … ms» یعنی ترافیک از نمایه عبور می‌کند.

اگر ارائه‌دهندهٔ شما لینک `throne://addsub/…` داده است، به‌جای مراحل 3 و 4 آن را روی گوشی باز کنید.

Throne برای لینک‌های متنی در منوی اشتراک‌گذاری Android دیده نمی‌شود. لینک را کپی کنید و از `وارد کردن از بریده‌دان` استفاده کنید.

## تفاوت‌ها با نسخهٔ دسکتاپ {#differences}

| حوزه | Throne دسکتاپ | Throne برای Android |
| --- | --- | --- |
| ترافیک چگونه به Throne می‌رسد | `حالتvpn` (Tun Mode) و `پروکسی سیستمی` (System Proxy) | `تنظیمات` (Settings) ← `عمومی` (General) ← `حالت سرویس` (Service mode): `VPN` (پیش‌فرض) یا `فقط به حالت پراکسی` (Proxy only). [حالت‌های VPN و پروکسی](@/android/modes.fa.md) را ببینید. |
| انتخاب برنامه‌ها | قوانین مسیریابی بر اساس نام یا مسیر پردازه (process) | پروکسی به‌تفکیک برنامه با `تانل‌کردن اپلیکیشن‌ها` (Apps VPN mode) و قوانین مسیریابی بر اساس برنامه |
| پشتیبان‌ها | فایل‌های `.thrbackup`، همچنین روی WebDAV | همین‌طور، ولی فقط با نمایه‌ها، نمایه‌های مسیریابی و تنظیمات. [پشتیبان‌گیری در WebDAV](@/guides/backup.fa.md#webdav) را ببینید. |
| MTU پیش‌فرض TUN | 1500 | 9000 |
| نمایه‌های مسیریابی خام (raw) | پشتیبانی می‌شود | پشتیبانی نمی‌شود. نمایه‌های خامِ پشتیبان دسکتاپ به‌صورت فقط‌خواندنی نگه داشته می‌شوند. |
| داشبورد sing-box | `Tools` → `Open Web dashboard`. API مربوط به sing-box به‌طور پیش‌فرض خاموش است. | منوی کناری ← `sing-box تنظیمات` (sing-box dashboard). این API به‌طور پیش‌فرض روشن است و فقط روی خود دستگاه گوش می‌دهد. |
| کیل‌سوییچ (kill switch) | [کیل‌سوییچ](@/advanced/kill_switch.fa.md) | گزینهٔ «Block connections without VPN» (مسدود کردن اتصال‌های بدون VPN) در Android نزدیک‌ترین گزینه است. [Always-on VPN](@/android/permissions.fa.md#always-on) را ببینید. |

TLS spoof، نمایه‌های Tailscale و هستهٔ اضافی (Extra Core)، OTP Manager، نقطه‌های پایانی OpenVPN و OpenConnect در نمایه‌های مسیریابی، Throne API، `thronectl` و حالت بدون رابط گرافیکی (headless) در Android موجود نیستند.

برای `نمودارهای زنده` (Live graphs) (سرعت، CPU، حافظه و اتصال‌های هسته) و `آزمایش سرعت اتصال فعلی` (Speed test current connection)، انگشت خود را روی نوار پایین صفحه نگه دارید.

## چیدمان فهرست نمایه‌ها {#layout}

- در حالت افقی، دکمهٔ `دوستونه` (Double column) در نوار ابزار کارت‌های کوچک‌تر را کنار هم نشان می‌دهد. در حالت عمودی، فهرست همیشه یک ستون دارد.
- `تنظیمات` (Settings) ← `ظاهر` (Appearance) ← `ردیف‌های فشردهٔ پروفایل` (Compact profile rows) هر نمایه را در یک خط، فقط با نام و تأخیر آن نشان می‌دهد.
- `تنظیمات` ← `ظاهر` ← `کارت‌های فشردهٔ گروه` (Compact group cards) کارت‌های صفحهٔ `گروه‌ها` (Groups) را کوتاه‌تر می‌کند. گروه‌های اشتراکی به‌جای پیوند و `به‌روزرسانی اشتراک` (Update subscription)، نوار مصرف، زمان باقی‌مانده و یک دکمهٔ تازه‌سازی نشان می‌دهند.

کارت‌های دوستونه و ردیف‌های فشرده دکمهٔ ویرایش و اشتراک‌گذاری ندارند. از ⋮ ← `ویرایش` (Edit) یا `اشتراک‌گذاری` (Share) در همان ردیف استفاده کنید.

## منوهای دسکتاپ در Android {#menus}

راهنماهای مشترک، منوهای نسخهٔ دسکتاپ را نشان می‌دهند. در Android همین گزینه‌ها در این جاها هستند:

| Throne دسکتاپ | Throne برای Android |
| --- | --- |
| `گروه ها` (Groups) ← `Manage Groups` | منوی کناری ← `گروه‌ها` (Groups) |
| `مسیریابی` (Routing) ← `تنظیمات مسیریابی` (Routing Settings) ← زبانهٔ `مسیر` (Route) | منوی کناری ← `مسیریابی` (Routing) |
| `تنظیمات مسیریابی` ← زبانهٔ `متداول` (Common) | `تنظیمات` ← `مسیریابی` (Routing) |
| `تنظیمات مسیریابی` ← زبانهٔ `دی‌ان‌اس` (DNS) | `تنظیمات` ← `DNS` |
| `تنظیمات مسیریابی` ← زبانهٔ `Warp` | `تنظیمات` ← `مسیریابی` ← `WARP` |
| `تنظیمات` ← `تنظیمات vpn` (Tun Settings) | `تنظیمات` ← `TUN / VPN` |
| `تنظیمات` ← `Preset Settings` | `تنظیمات` ← `از پیش‌تنظیم‌ها` (Presets) |
| `تنظیمات` ← `تنظیمات پایه` (Basic Settings) ← `اشتراک` (Subscription) | `تنظیمات` ← `اشتراک‌ها` (Subscriptions) |
| `تنظیمات` ← `تنظیمات پایه` ← `Backup and Restore` | منوی کناری ← `ابزارها` (Tools) |
| `تنظیمات` ← `تنظیمات پایه` ← `Diagnostics` | `تنظیمات` ← `عیب‌یابی` (Diagnostics) |
