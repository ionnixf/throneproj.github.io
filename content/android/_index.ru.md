Throne для Android — это версия Throne для устройств на Android. Раньше она называлась NekoBox for Android. Начиная с версии 2.0.0 она работает на том же ядре, что и Throne для компьютера (ThroneCore), поэтому группы, подписки, профили маршрутизации, DNS, пресеты, автовыбор, WARP и резервные копии работают в обоих приложениях одинаково.

Страницы этого раздела описывают то, что относится только к Android: установку, разрешения, режимы VPN и прокси, виджеты, Android TV и устранение неполадок. Если вы впервые пользуетесь приложением, выполните шаги из раздела [Быстрый старт](#quick-start), а затем прочитайте страницу [Разрешения и работа в фоне](@/android/permissions.ru.md), чтобы Android не останавливал VPN.

Функции, общие для обоих приложений, описаны в этих руководствах:

- [Подписки и группы](@/guides/subscriptions.ru.md)
- [Маршрутизация](@/guides/routing.ru.md)
- [DNS](@/guides/dns.ru.md)
- [Тестирование и автовыбор](@/guides/testing.ru.md)
- [Cloudflare WARP](@/advanced/warp.ru.md)
- [Перенос между компьютером и Android](@/guides/backup.ru.md#desktop-android)

Пункт `Документы` (Documentation) в боковом меню приложения (выдвижной панели) открывает этот сайт.

## Быстрый старт {#quick-start}

1. Установите APK для своего устройства. Большинству телефонов нужен `arm64-v8a`. См. [Выбор нужного APK](@/android/installation.ru.md#choose-apk).
2. Откройте Throne. На Android 13 и новее разрешите уведомления.
3. Когда Throne покажет запрос «Оставлять Throne запущенным» (Keep Throne running), нажмите `Разрешить` (Allow) и подтвердите в диалоге Android. См. [Разрешения и работа в фоне](@/android/permissions.ru.md).
4. Скопируйте URL своей подписки.
5. На экране `Конфигурация` (Profiles) нажмите на панели инструментов `Добавить профиль` (Add profile) — значок страницы со знаком плюс, — а затем `Импорт из буфера обмена` (Import from clipboard). Чтобы вместо этого отсканировать QR-код, выберите `Отсканировать QR-код` (Scan QR code).
6. Throne распознает URL и спросит «Как обновить?» (How to update?). Нажмите `Создать новую группу подписок` (Create new subscription group). Throne добавит группу, названную по имени хоста из URL, и загрузит её профили.
7. Нажмите на вкладку новой группы.
8. Нажмите ⋮ `Другие параметры` (More options) → `Тест` (Test) → `URL-тест` (URL test). В 2.0.4 и старее `URL-тест` находится прямо в меню ⋮. На панели отображаются ход проверки и сводка результатов. У каждого профиля в списке показан его собственный результат.
9. Когда тест завершится, нажмите `Выбрать самый быстрый` (Select fastest) или нажмите на работающий профиль.
10. Нажмите круглую кнопку подключения внизу экрана. В первый раз Android спросит, может ли Throne настроить VPN-подключение. Разрешите это.
11. Чтобы проверить подключение, нажмите на полосу внизу экрана («Подключено, нажмите для проверки подключения»). Если трафик проходит через профиль, на ней появится «HTTP-соединение установлено за … мс» (Success: HTTP handshake took …ms), а начиная с 2.0.3 — «HTTP: … мс» (HTTP: … ms). Начиная с 2.0.2 на полосе также показано место, где ваш трафик выходит в интернет. Throne узнаёт его у сервиса определения IP через это подключение. Начиная с 2.0.3 параметр `Настройки` (Settings) → `Тестирование` (Testing) → `Look up exit country` выключает это определение, а `Lookup service` выбирает сервис.

Если провайдер дал вам ссылку `throne://addsub/…`, откройте её на телефоне вместо шагов 4–6. Throne спросит «Добавить эту подписку?» (Add this subscription?), добавит группу, загрузит её профили и откроет экран `Группы` (Groups). Затем откройте экран `Конфигурация` (Profiles) и продолжайте с шага 7.

Throne не появляется в меню Android «Поделиться», когда вы делитесь текстовой ссылкой из другого приложения. Вместо этого скопируйте ссылку и используйте `Импорт из буфера обмена` (Import from clipboard).

## Отличия от версии для компьютера {#differences}

У двух приложений общее ядро и большинство настроек. Вот что работает по-разному:

| Область | Throne для компьютера | Throne для Android |
| --- | --- | --- |
| Как трафик попадает в Throne | Флажки `Режим TUN` (Tun Mode) и `Системный прокси` (System Proxy) | `Настройки` (Settings) → `Основные` (General) → `Сервисный режим` (Service mode): `VPN` (по умолчанию) или `Только прокси` (Proxy only). См. [Режимы VPN и прокси](@/android/modes.ru.md). |
| Выбор приложений | Правила маршрутизации по имени или пути процесса | Прокси для отдельных приложений — `Режим VPN для приложений` (Apps VPN mode) — и правила маршрутизации по приложениям |
| Резервные копии | Файлы `.thrbackup`, начиная с 1.4.0 в том числе на сервере WebDAV | Файлы `.thrbackup` только с профилями, профилями маршрутизации и настройками, в том числе на сервере WebDAV. См. [Резервные копии на WebDAV](@/guides/backup.ru.md#webdav). |
| MTU TUN по умолчанию | 1500 | 9000 |
| Уровень логирования ядра по умолчанию | `info` | `warn` |
| Ссылка `throne://add/…`, открытая из другого приложения | Сразу импортирует профиль | Сначала спрашивает «Импортировать профиль» (Import profile) |
| Raw-профили маршрутизации | Поддерживаются | Не поддерживаются. Raw-профили из резервной копии с компьютера сохраняются только для чтения. |
| TLS spoof, профили Tailscale и дополнительного ядра (Extra Core), менеджер OTP (OTP Manager), конечные точки OpenVPN и OpenConnect в профилях маршрутизации | Доступны | Недоступны |
| Панель sing-box | `Утилиты` (Tools) → `Открыть веб-панель` (Open Web dashboard). API sing-box, через который работает панель, по умолчанию выключен. | Боковое меню → `Панель sing-box` (sing-box dashboard) (начиная с 2.0.2). API sing-box по умолчанию включён и доступен только на самом устройстве. |
| Kill switch | [Kill Switch](@/advanced/kill_switch.ru.md) | Недоступен. Ближе всего к нему параметр Android «Block connections without VPN» (блокировать подключения без VPN). См. [Постоянная VPN](@/android/permissions.ru.md#always-on). |
| Throne API, `thronectl` и режим headless | Доступны. См. [Throne API и thronectl](@/advanced/api.ru.md) и [Throne в режиме headless](@/headless/_index.ru.md). | Недоступны |

Ссылки для обмена, например `vless://…`, открытые из другого приложения, тоже сначала вызывают вопрос «Импортировать профиль». Ссылки на профили, которые вы вставляете через `Импорт из буфера обмена` или сканируете как QR-код, импортируются без вопросов.

Кроме того, на Android есть виджеты главного экрана, плитка быстрых настроек и системная постоянная VPN (Always-on VPN). См. [Виджеты, плитка и автоматизация](@/android/widgets.ru.md) и [Постоянная VPN](@/android/permissions.ru.md#always-on). Правилам маршрутизации, которые проверяют подключённую сеть Wi-Fi, на Android нужен доступ к местоположению. См. [Местоположение для правил Wi-Fi](@/android/permissions.ru.md#location).

В боковом меню также есть два экрана, на которых можно следить за подключением:

- `Панель sing-box` (sing-box dashboard) (начиная с 2.0.2) показывает текущий трафик, соединения и лог работающего ядра. Для неё нужны запущенный профиль и Android System WebView. Файлы панели входят в приложение. Чтобы скрыть этот пункт, выключите `Настройки` (Settings) → `Ядро` (Core) → `Включить API sing-box` (Enable sing-box API).
- `Графики в реальном времени` (Live graphs) (начиная с 2.0.3) показывает скорость через прокси и напрямую за последние минуты, а также загрузку процессора, память и соединения ядра. В 2.0.3, чтобы открыть этот экран, нажмите и удерживайте полосу внизу экрана. Начиная с 2.0.4 долгое нажатие на полосу открывает меню с пунктами `Графики в реальном времени` (Live graphs) и `Тест скорости текущего соединения` (Speed test current connection). Для теста скорости нужно работающее подключение.

## Вид списка профилей {#layout}

На экране `Конфигурация` (Profiles) у каждого профиля есть карточка с кнопками для редактирования и отправки. Эти параметры меняют вид списков:

- В альбомной ориентации кнопка `Два столбца` (Double column) на панели инструментов показывает карточки поменьше рядом друг с другом, а `Один столбец` (Single column) возвращает прежний вид. В портретной ориентации в списке всегда один столбец. В 2.0.4 и старее раскладку выбирают через ⋮ → `Внешний вид` (Appearance) в любой ориентации.
- `Настройки` (Settings) → `Внешний вид` (Appearance) → `Компактные строки профилей` (Compact profile rows) (начиная с 2.0.5) показывает каждый профиль одной короткой строкой только с именем и задержкой.
- `Настройки` → `Внешний вид` → `Компактные карточки групп` (Compact group cards) (начиная с 2.0.5) сокращает карточки на экране `Группы` (Groups). Группы подписок показывают шкалу использования и оставшееся время вместо ссылки и подробностей подписки, а вместо `Обновить подписку` (Update subscription) — кнопку обновления.

У карточек в два столбца и компактных строк нет кнопок редактирования и отправки. Используйте вместо них ⋮ → `Редактировать` (Edit) или `Поделиться` (Share) в строке профиля.

## Меню версии для компьютера на Android {#menus}

В общих руководствах показаны меню версии для компьютера. На Android те же параметры находятся здесь:

| Throne для компьютера | Throne для Android |
| --- | --- |
| `Группы` (Groups) → `Управление группами` (Manage Groups) | Боковое меню → `Группы` (Groups) |
| `Маршрутизация` (Routing) → `Настройки маршрутизации` (Routing Settings) → вкладка `Маршрутизация` (Route) | Боковое меню → `Маршруты` (Routing) |
| `Настройки маршрутизации` (Routing Settings) → вкладка `Основные` (Common) | `Настройки` (Settings) → `Маршрутизация` (Routing) |
| `Настройки маршрутизации` → вкладка `DNS` | `Настройки` → `DNS` |
| `Настройки маршрутизации` → вкладка `Warp` | `Настройки` → `Маршрутизация` → `WARP` |
| `Настройки` (Settings) → `Настройки режима TUN` (Tun Settings) | `Настройки` → `TUN / VPN` |
| `Настройки` → `Предустановленные настройки` (Preset Settings) | `Настройки` → `Пресеты` (Presets) |
| `Настройки` → `Основные настройки` (Basic Settings) → `Подписка` (Subscription) | `Настройки` → `Подписки` (Subscriptions) |
| `Настройки` → `Основные настройки` → `Резервное копирование и восстановление` (Backup and Restore) | Боковое меню → `Инструменты` (Tools) |
| `Настройки` → `Основные настройки` → `Диагностика` (Diagnostics) | `Настройки` → `Диагностика` (Diagnostics) (начиная с 2.0.3) |
| `Утилиты` (Tools) → `Открыть веб-панель` (Open Web dashboard) | Боковое меню → `Панель sing-box` (sing-box dashboard) (начиная с 2.0.2) |
