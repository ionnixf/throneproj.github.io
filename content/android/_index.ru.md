Throne для Android (раньше NekoBox for Android) работает на том же ядре, что и Throne для компьютера, поэтому группы, подписки, профили маршрутизации, DNS, пресеты, автовыбор, WARP и резервные копии работают в обоих приложениях одинаково. Они описаны в руководствах: [Подписки и группы](@/guides/subscriptions.ru.md), [Маршрутизация](@/guides/routing.ru.md), [DNS](@/guides/dns.ru.md), [Тестирование и автовыбор](@/guides/testing.ru.md), [Cloudflare WARP](@/advanced/warp.ru.md) и [Перенос между компьютером и Android](@/guides/backup.ru.md#desktop-android). Этот раздел описывает то, что относится только к Android.

## Быстрый старт {#quick-start}

1. Установите APK для своего устройства. Большинству телефонов нужен `arm64-v8a`. См. [Выбор нужного APK](@/android/installation.ru.md#choose-apk).
2. Откройте Throne. Разрешите уведомления, а когда Throne попросит оставлять его запущенным в фоне, нажмите `Разрешить` (Allow). См. [Разрешения и работа в фоне](@/android/permissions.ru.md).
3. Скопируйте URL своей подписки. На экране `Конфигурация` (Profiles) нажмите `Добавить профиль` (Add profile) — значок страницы со знаком плюс — → `Импорт из буфера обмена` (Import from clipboard) или `Отсканировать QR-код` (Scan QR code) для QR-кода.
4. Нажмите `Создать новую группу подписок` (Create new subscription group). Throne добавит группу и загрузит её профили.
5. Откройте вкладку новой группы и нажмите ⋮ → `Тест` (Test) → `URL-тест` (URL test). Когда тест завершится, нажмите `Выбрать самый быстрый` (Select fastest) или нажмите на работающий профиль.
6. Нажмите круглую кнопку подключения внизу экрана и разрешите запрос VPN.
7. Чтобы проверить подключение, нажмите на полосу внизу экрана. «HTTP: … мс» означает, что трафик проходит через профиль.

Если провайдер дал вам ссылку `throne://addsub/…`, откройте её на телефоне вместо шагов 3 и 4.

Throne не появляется в меню Android «Поделиться» для текстовых ссылок. Скопируйте ссылку и используйте `Импорт из буфера обмена` (Import from clipboard).

## Отличия от версии для компьютера {#differences}

| Область | Throne для компьютера | Throne для Android |
| --- | --- | --- |
| Как трафик попадает в Throne | `Режим TUN` (Tun Mode) и `Системный прокси` (System Proxy) | `Настройки` (Settings) → `Основные` (General) → `Сервисный режим` (Service mode): `VPN` (по умолчанию) или `Только прокси` (Proxy only). См. [Режимы VPN и прокси](@/android/modes.ru.md). |
| Выбор приложений | Правила маршрутизации по имени или пути процесса | Прокси для отдельных приложений — `Режим VPN для приложений` (Apps VPN mode) — и правила маршрутизации по приложениям |
| Резервные копии | Файлы `.thrbackup`, в том числе на WebDAV | То же, но только с профилями, профилями маршрутизации и настройками. См. [Резервные копии на WebDAV](@/guides/backup.ru.md#webdav). |
| MTU TUN по умолчанию | 1500 | 9000 |
| Raw-профили маршрутизации | Поддерживаются | Не поддерживаются. Raw-профили из резервной копии с компьютера сохраняются только для чтения. |
| Панель sing-box | `Утилиты` (Tools) → `Открыть веб-панель` (Open Web dashboard). API sing-box по умолчанию выключен. | Боковое меню → `Панель sing-box` (sing-box dashboard). API по умолчанию включён и доступен только на самом устройстве. |
| Kill switch | [Kill Switch](@/advanced/kill_switch.ru.md) | Ближе всего к нему параметр Android «Block connections without VPN» (блокировать подключения без VPN). См. [Постоянная VPN](@/android/permissions.ru.md#always-on). |

На Android недоступны TLS spoof, профили Tailscale и дополнительного ядра (Extra Core), менеджер OTP (OTP Manager), конечные точки OpenVPN и OpenConnect в профилях маршрутизации, Throne API, `thronectl` и режим headless.

Долгое нажатие на полосу внизу экрана открывает `Графики в реальном времени` (Live graphs) — скорость, загрузку процессора, память и соединения ядра — и `Тест скорости текущего соединения` (Speed test current connection).

## Вид списка профилей {#layout}

- В альбомной ориентации кнопка `Два столбца` (Double column) на панели инструментов показывает карточки поменьше рядом друг с другом. В портретной ориентации в списке всегда один столбец.
- `Настройки` (Settings) → `Внешний вид` (Appearance) → `Компактные строки профилей` (Compact profile rows) показывает каждый профиль одной строкой только с именем и задержкой.
- `Настройки` → `Внешний вид` → `Компактные карточки групп` (Compact group cards) сокращает карточки на экране `Группы` (Groups). Группы подписок показывают шкалу использования, оставшееся время и кнопку обновления вместо ссылки и `Обновить подписку` (Update subscription).

У карточек в два столбца и компактных строк нет кнопок редактирования и отправки. Используйте ⋮ → `Редактировать` (Edit) или `Поделиться` (Share) в строке профиля.

## Меню версии для компьютера на Android {#menus}

В общих руководствах показаны меню версии для компьютера. На Android те же параметры находятся здесь:

| Throne для компьютера | Throne для Android |
| --- | --- |
| `Группы` (Groups) → `Управление группами` (Manage Groups) | Боковое меню → `Группы` (Groups) |
| `Маршрутизация` (Routing) → `Настройки маршрутизации` (Routing Settings) → вкладка `Маршрутизация` (Route) | Боковое меню → `Маршруты` (Routing) |
| `Настройки маршрутизации` (Routing Settings) → вкладка `Основные` (Common) | `Настройки` (Settings) → `Маршрутизация` (Routing) |
| `Настройки маршрутизации` → вкладка `DNS` | `Настройки` → `DNS` |
| `Настройки маршрутизации` → вкладка `Warp` | `Настройки` → `Маршрутизация` → `WARP` |
| `Настройки` (Settings) → `Настройки режима TUN` (Tun Settings) | `Настройки` → `TUN / VPN` |
| `Настройки` → `Предустановленные настройки` (Preset Settings) | `Настройки` → `Пресеты` (Presets) |
| `Настройки` → `Основные настройки` (Basic Settings) → `Подписка` (Subscription) | `Настройки` → `Подписки` (Subscriptions) |
| `Настройки` → `Основные настройки` → `Резервное копирование и восстановление` (Backup and Restore) | Боковое меню → `Инструменты` (Tools) |
| `Настройки` → `Основные настройки` → `Диагностика` (Diagnostics) | `Настройки` → `Диагностика` (Diagnostics) |
