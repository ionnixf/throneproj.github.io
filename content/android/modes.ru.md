## Выбор сервисного режима {#service-mode}

Режим задаётся в `Настройки` (Settings) → `Основные` (General) → `Сервисный режим` (Service mode). Смена режима останавливает текущее подключение; нажмите кнопку подключения, чтобы запустить его снова.

| Режим | Что делает | Когда использовать |
| --- | --- | --- |
| `VPN` (по умолчанию) | Android направляет трафик всех приложений или только выбранных вами в Throne через виртуальный сетевой интерфейс (TUN). | Вы хотите, чтобы все приложения использовали Throne. Это обычный выбор. |
| `Только прокси` (Proxy only) | Throne открывает только локальный прокси SOCKS5 и HTTP на `127.0.0.1`, по умолчанию на порту `2080`. VPN не создаётся. | Другое VPN-приложение должно оставаться подключённым, Throne нужен только в приложениях с настройками прокси или ваше устройство не может выдать доступ к VPN. |

Если вы меняете параметр с этой страницы, пока Throne подключён, нажмите `Применить` (Apply), когда Throne покажет «Перезагрузите прокси-сервис, чтобы применить изменения» (Reload proxy service to apply changes), или переподключитесь.

## Режим VPN {#vpn-mode}

В режиме VPN Throne отправляет каждое подключение ваших приложений через прокси, напрямую или блокирует его — как указано в вашем профиле маршрутизации.

- Android одновременно запускает только один VPN. Подключение Throne отключает VPN любого другого приложения.
- Устройства, подключённые к точке доступа вашего телефона, не используют VPN. Чтобы они могли пользоваться прокси, используйте [доступ из локальной сети](#lan-sharing).
- Чтобы исключить некоторые приложения из VPN или пропускать через него только некоторые приложения, используйте [прокси для отдельных приложений](#per-app-proxy).
- Если Throne назначен постоянной VPN (Always-on VPN), Android запускает его в режиме VPN. См. [Постоянная VPN](@/android/permissions.ru.md#always-on).

### HTTP-прокси VPN {#http-proxy}

На Android 10 и новее параметр `Настройки` (Settings) → `Входящие` (Inbound) → `Добавлять HTTP-прокси в VPN` (Append HTTP proxy to VPN) (по умолчанию выключен) также указывает локальный прокси Throne в качестве HTTP-прокси сети VPN. Тогда приложения, которые следуют системным настройкам прокси (например, большинство браузеров), отправляют свой веб-трафик на этот прокси, а не через VPN-интерфейс. Этот трафик по-прежнему подчиняется вашему профилю маршрутизации.

Параметр недоступен, пока включён `Включить авторизацию` (Enable authorization), потому что Android не может передать приложениям имя пользователя и пароль. Домены из `Список обхода HTTP-прокси` (HTTP proxy bypass list), по одному в строке, например `*example.com`, подключаются без этого прокси.

### Приложения в обход VPN {#allow-bypass}

`Настройки` (Settings) → `Основные` (General) → `Разрешить приложениям обходить VPN` (Allow apps to bypass VPN) (по умолчанию выключен) позволяет приложениям, которые это запрашивают, подключаться в обход VPN, например push-уведомлениям Google (FCM). Такие соединения идут напрямую и не подчиняются вашему профилю маршрутизации. Android игнорирует этот параметр, пока постоянная VPN блокирует подключения без VPN.

## Режим «Только прокси» {#proxy-only}

В режиме `Только прокси` Throne запускает локальный прокси и ничего больше. Android не запрашивает разрешение на VPN, и Throne используют только те приложения, которые вы направили на этот прокси. Настройки TUN и прокси для отдельных приложений не действуют.

1. Установите `Настройки` (Settings) → `Основные` (General) → `Сервисный режим` (Service mode) в `Только прокси` и подключитесь.
2. В приложении, которое должно использовать Throne, укажите прокси SOCKS5 или HTTP с сервером `127.0.0.1` и портом `2080` (или портом, заданным в `Порт прокси SOCKS5` (Proxy port)). Если включён `Включить авторизацию` (Enable authorization), также введите имя пользователя и пароль.

В этом режиме собственные запросы Throne, например обновления подписок, идут через локальный прокси, пока запущен профиль, и напрямую, пока ни один профиль не запущен, если не включён `Настройки` → `Подписки` (Subscriptions) → `Использовать прокси` (Use proxy).

## Прокси для отдельных приложений {#per-app-proxy}

Прокси для отдельных приложений определяет, какие приложения используют VPN. Он работает только в режиме VPN.

1. Включите `Настройки` (Settings) → `TUN / VPN` → `Режим VPN для приложений` (Apps VPN mode). Откроется список приложений.
2. Выберите режим в верхней части списка: `Прокси` (Proxy) пропускает через VPN только выбранные приложения, а `Обход` (Bypass) оставляет выбранные приложения вне VPN.
3. Нажимайте на приложения, чтобы выбрать их. `Поиск…` (Search…) находит приложение по названию или имени пакета. Приложения с общим идентификатором пользователя (user ID) выбираются вместе.

Если не выбрано ни одного приложения, VPN используют все приложения. В режиме `Прокси`, если ни одно из выбранных приложений не установлено, VPN не использует ни одно приложение. Чтобы выключить прокси для отдельных приложений, выключите переключатель `Режим VPN для приложений` или выберите `Выключенный` (Off) в списке; Throne сохраняет ваш выбор до следующего раза. Если список остаётся пустым, см. [Установленные приложения](@/android/permissions.ru.md#installed-apps).

`Автоматический выбор прокси-приложений` (Auto select proxy apps) выбирает приложения из встроенного списка примерно из 390 приложений, которым часто нужен прокси, например приложений Google, YouTube, Instagram и Netflix, так что эти приложения используют VPN, а остальные — нет. Он заменяет ваш выбор среди установленных приложений.

`Добавить имя пакета…` (Add package name…) добавляет приложения, которые список не может показать. `Экспорт в буфер обмена` (Export to clipboard) и `Импорт из буфера обмена` (Import from clipboard) копируют режим и выбор в виде обычного текста: первая строка — `true` для режима `Обход` или `false` для режима `Прокси`, затем по одному имени пакета в строке.

```text
false
com.google.android.youtube
org.telegram.messenger
```

Без строки `true` или `false` импорт сохраняет текущий режим и заменяет только выбор. Если какая-то строка не является именем пакета, Throne отклоняет весь список.

Чтобы направить приложение в определённый outbound, используйте вместо этого правило маршрутизации с условием `Приложения` (Apps). См. [Маршрутизация на Android](@/guides/routing.ru.md#android). Такое правило видит только приложения, которые используют VPN: если прокси для отдельных приложений не пускает приложение в VPN, его правило никогда не срабатывает. В списке приложений правила маршрутизации пункт ⋮ → `Скопировать в режим VPN для приложений` (Copy to Apps VPN mode) добавляет эти приложения в прокси для отдельных приложений и объясняет варианты, прежде чем что-либо изменить.

## Доступ из локальной сети {#lan-sharing}

Доступ из локальной сети позволяет другим устройствам в вашей сети или на точке доступа вашего телефона использовать Throne на телефоне как прокси. Он работает в обоих сервисных режимах.

1. Откройте `Настройки` (Settings) → `Входящие` (Inbound) и включите `Разрешить подключения из локальной сети` (Allow connections from the LAN).
2. Включите `Включить авторизацию` (Enable authorization) и задайте `Имя пользователя` (Username) и `Пароль` (Password).
3. Запомните значение `Порт прокси SOCKS5` (Proxy port), по умолчанию `2080`.
4. Узнайте IP-адрес телефона в настройках Wi-Fi Android, в сведениях о подключённой сети. Устройства на вашей точке доступа используют адрес маршрутизатора (шлюза), который они показывают для своего подключения.
5. На другом устройстве укажите прокси SOCKS5 или HTTP с этим адресом, портом, именем пользователя и паролем.

{% alert_warning() %}
Без авторизации ваш прокси может использовать любое устройство в той же сети.
{% end %}

## Настройки TUN / VPN {#tun-settings}

Эти настройки находятся в `Настройки` (Settings) → `TUN / VPN` и действуют только в режиме VPN.

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `MTU` | `9000` | Максимальный размер пакета VPN-интерфейса. Если некоторые приложения или сайты не работают, а другие работают, задайте `1500` и переподключитесь. Нажмите на параметр и удерживайте его, чтобы ввести любое значение от 1000 до 10000. |
| `Tun IPv6` | Выкл. | Направляет IPv6 через VPN-интерфейс. Когда параметр выключен, IPv6-подключения сразу завершаются ошибкой, поэтому приложения используют IPv4. Включайте его, только если ваш сервер поддерживает IPv6. |
| `Маршрутизация tun` (Tun routing) | Выкл. | Оставляет диапазоны IP, которые ваш профиль маршрутизации направляет в `direct`, вне VPN-интерфейса. |
| `Обходить частные диапазоны` (Bypass private ranges) | Вкл. | Оставляет `Частные диапазоны` (Private ranges) — локальные сети — вне VPN-интерфейса, чтобы устройства в вашей локальной сети были доступны напрямую. |
| `CIDR IPv4` (IPv4 CIDR), `CIDR IPv6` (IPv6 CIDR) | `172.19.0.1/24`, `fdfe:dcba:9876::1/96` | Адреса VPN-интерфейса. |

Если правило маршрутизации направляет адреса из частного диапазона в outbound, отличный от `direct`, или отклоняет их, Throne оставляет этот диапазон внутри VPN-интерфейса, чтобы правило работало. Строгий маршрут (strict route) всегда включён.

При восстановлении настроек из резервной копии с компьютера переносится и MTU версии для компьютера — `1500`, если вы не меняли его там.

## Настройки входящих подключений {#inbound-settings}

`Настройки` (Settings) → `Входящие` (Inbound) управляет локальным прокси Throne — смешанным входом (mixed inbound), который принимает SOCKS5 и HTTP на одном порту.

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Отключить смешанный вход (mixed)` (Disable mixed inbound) | Выкл. | В режиме VPN Throne не открывает локальный прокси. Это также отключает [HTTP-прокси VPN](#http-proxy) и доступ из локальной сети. В режиме `Только прокси` не действует. |
| `Порт прокси SOCKS5` (Proxy port) | `2080` | Порт локального прокси. В рабочем профиле или у другого пользователя Android по умолчанию используется 2080 плюс номер этого пользователя. |
| `Включить авторизацию` (Enable authorization) | Выкл. | Каждый клиент должен передавать `Имя пользователя` (Username) и `Пароль` (Password). |
| `Порт DNS-сервера` (DNS server port) | `5533` | Порт локального DNS-сервера Throne на `127.0.0.1`. Выберите другой порт, если этот уже занят другим приложением или другим пользователем Android. См. [DNS на Android](@/guides/dns.ru.md#android). |
| `Пользовательский входящий` (Custom inbound) | `{"inbounds": []}` | Дополнительные входящие подключения (inbounds) sing-box в формате JSON, которые добавляются в конфигурацию без изменений. |
