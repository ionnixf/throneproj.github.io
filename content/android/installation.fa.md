Throne برای Android به Android 7.0 یا جدیدتر نیاز دارد. این برنامه روی گوشی‌ها، تبلت‌ها و Android TV اجرا می‌شود.

## انتخاب APK مناسب {#choose-apk}

هر انتشار برای هر نوع پردازنده (ABI) یک APK دارد:

| APK | دستگاه‌های معمول |
| --- | --- |
| `Throne-<version>-arm64-v8a.apk` | تقریباً همهٔ گوشی‌ها و تبلت‌های سال‌های اخیر |
| `Throne-<version>-armeabi-v7a.apk` | گوشی‌های قدیمی‌تر 32 بیتی، بسیاری از باکس‌ها و دانگل‌های Android TV |
| `Throne-<version>-x86_64.apk` | شبیه‌سازها، برخی Chromebookها و رایانه‌های شخصی |

آنچه اهمیت دارد سیستم Android است، نه پردازنده: بسیاری از باکس‌های تلویزیون پردازندهٔ 64 بیتی دارند اما نسخهٔ 32 بیتی Android را اجرا می‌کنند، پس به `armeabi-v7a` نیاز دارند. با adb، این فرمان ABI را چاپ می‌کند:

```bash
adb shell getprop ro.product.cpu.abi
```

اگر مطمئن نیستید، `arm64-v8a` را امتحان کنید. اگر Android آن را نصب نکرد، از `armeabi-v7a` استفاده کنید.

## دانلود و بررسی {#download}

APK را از صفحهٔ [دانلود](@/downloads.fa.md) یا از [انتشارهای GitHub](https://github.com/throneproj/ThroneForAndroid/releases) دانلود کنید. برای اطمینان از سالم بودن فایل (اختیاری)، آن را همراه فایل `SHA256SUMS` همان انتشار در یک پوشه قرار دهید و این فرمان را اجرا کنید:

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

خروجی باید برای فایل شما `OK` را نشان دهد. در macOS فرمان `shasum -a 256 Throne-2.0.6-arm64-v8a.apk` و در Windows فرمان `Get-FileHash .\Throne-2.0.6-arm64-v8a.apk -Algorithm SHA256` را اجرا کنید و چک‌سام را با خط مربوط به فایل خود در `SHA256SUMS` مقایسه کنید.

## نصب {#install}

اگر Throne برای Android نسخهٔ 1.x نصب است، ابتدا [ارتقا از 1.x یا NekoBox](#upgrading) را بخوانید.

1. APK دانلودشده را باز کنید.
2. اگر Android جلوی نصب را گرفت، در پیام روی `Settings` (تنظیمات) بزنید و `Allow from this source` (اجازه از این منبع) را روشن کنید. در Android 7، به‌جای آن گزینهٔ `Unknown sources` (منابع ناشناس) را در تنظیمات امنیتی Android روشن کنید.
3. برگردید و روی `Install` (نصب) بزنید.
4. Throne را باز کنید و به پرسش‌های اجرای نخست پاسخ دهید. [مجوزها و اجرا در پس‌زمینه](@/android/permissions.fa.md) را ببینید.

برای Android TV، صفحهٔ [Android TV](@/android/tv.fa.md#install-tv) را ببینید.

## ارتقا از 1.x یا NekoBox {#upgrading}

Throne برای Android از نسخهٔ 2.0.0 با کلید تازه‌ای امضا می‌شود و از قالب داده‌ای جدیدی استفاده می‌کند. Android نمی‌تواند آن را روی نسخهٔ 1.x نصب کند، برنامه بدون هیچ نمایه، گروه یا تنظیماتی شروع به کار می‌کند و پشتیبان‌های قدیمی (فایل‌های `throne_backup_….json` و فایل‌های `.zip` روی WebDAV) را بازیابی نمی‌کند؛ فقط فایل‌های `.thrbackup` را.

{% alert_warning() %}
حذف برنامهٔ قدیمی همهٔ نمایه‌ها، گروه‌ها، قوانین مسیریابی و تنظیمات آن را پاک می‌کند. پیش از حذف، هر چه را لازم دارید ذخیره کنید.
{% end %}

1. در برنامهٔ قدیمی، نشانی (URL) هر اشتراک را کپی کنید: منوی کناری ← `گروه‌ها` (Group)، دکمهٔ ویرایش گروه (نماد مداد) را بزنید و `لینک اشتراک` (Subscription Link) را کپی کنید. از `اشتراک‌گذاری گروه اشتراکی` (Share Subscription) استفاده نکنید: این گزینه یک لینک `sn://` کپی می‌کند که برنامهٔ جدید نمی‌تواند آن را بخواند.
2. نمایه‌هایی را که از اشتراک نیامده‌اند صادر (export) کنید: منوی گروه ← `صدور` (Export) ← `صدور به صورت فایل` (Export to file). نمایه‌های WireGuard، SSH، ShadowTLS، Mieru، زنجیره (chain) و پیکربندی سفارشی (custom config) به‌صورت لینک `sn://` صادر می‌شوند که قابل وارد کردن نیست؛ پس تنظیمات آن‌ها را یادداشت کنید.
3. اگر از Throne دسکتاپ با همین نمایه‌ها استفاده می‌کنید، می‌توانید به‌جای این کار در آنجا یک پشتیبان بسازید و آن را روی گوشی بازیابی کنید. [جابه‌جایی بین دسکتاپ و Android](@/guides/backup.fa.md#desktop-android) را ببینید.
4. برنامهٔ قدیمی را حذف کنید و برنامهٔ جدید را [نصب](#install) کنید.
5. اشتراک‌های خود را دوباره اضافه کنید (`اضافه‌کردن پراکسی جدید` (Add profile) ← `وارد کردن از بریده‌دان` (Import from clipboard) ← `ایجاد گروه اشتراک جدید` (Create new subscription group))، فایل صادرشده را وارد کنید (`اضافه‌کردن پراکسی جدید` ← `وارد کردن از یک فایل` (Import from file))، یا پشتیبان دسکتاپ را بازیابی کنید (منوی کناری ← `ابزارها` (Tools) ← `بازیابی` (Restore)).

برنامهٔ اصلی **NekoBox for Android** نام بستهٔ (package name) متفاوتی دارد، بنابراین Throne در کنار آن نصب می‌شود. Throne نمی‌تواند داده‌ها یا پشتیبان‌های آن را بخواند: اشتراک‌های خود را با لینک‌هایشان منتقل کنید.

## به‌روزرسان درون‌برنامه‌ای {#updater}

نسخه‌های GitHub خودشان را به‌روزرسانی می‌کنند:

1. `درباره برنامه` (About) را در منوی کناری باز کنید و روی `بررسی به‌روزرسانی‌ها` (Check for updates) بزنید.
2. اگر نسخهٔ جدیدتری وجود داشته باشد، روی `به‌روزرسانی` (Update) بزنید.
3. بار اول، Throne اجازهٔ نصب برنامه را می‌خواهد. روی `باز کردن تنظیمات` (Open settings) بزنید، اجازه بدهید و برگردید.
4. Throne فایل APK را دانلود و بررسی می‌کند. وقتی Android خواست، نصب را تأیید کنید.

اتصال در حین جایگزینی برنامه قطع می‌شود و پس از آن دوباره برقرار می‌شود.

در `تنظیمات` (Settings) ← `عمومی` (General) ← `به‌روزرسانی‌ها` (Updates)، گزینهٔ `بررسی روزانه به‌روزرسانی‌ها` (Check for updates daily) نسخه‌های جدید را با اعلان خبر می‌دهد و `اجازه به‌روزرسانی به نسخه‌های بتا` (Allow updating to beta versions) پیش‌انتشارهای صفحهٔ انتشارهای GitHub را هم پیشنهاد می‌دهد. هر دو به‌طور پیش‌فرض خاموش‌اند.

Android به‌روزرسانی را فقط وقتی نصب می‌کند که با همان کلید برنامهٔ نصب‌شده امضا شده باشد. بنابراین نسخه‌ای از منبعی دیگر و نسخهٔ GitHub نمی‌توانند یکدیگر را به‌روزرسانی کنند. برای جابه‌جایی بین آن‌ها، پشتیبان بگیرید (منوی کناری ← `ابزارها` ← `ایجاد پشتیبان` (Create backup))، برنامه را حذف کنید، نسخهٔ دیگر را نصب کنید و پشتیبان را بازیابی کنید. برای خطاهای به‌روزرسان، [مشکلات به‌روزرسانی](@/android/troubleshooting.fa.md#updates) را ببینید.

Throne برای Android هنوز در F-Droid نیست ([#37](https://github.com/throneproj/ThroneForAndroid/issues/37)).

## نسخه‌های پیش‌نمایش {#preview}

نسخه‌های پیش‌نمایش تازه‌ترین تغییرات را دارند و برای آزمایش در نظر گرفته شده‌اند، پس ممکن است باگ داشته باشند. توسعه‌دهندگان هر وقت به آزمایش‌کننده نیاز داشته باشند، یک نسخهٔ پیش‌نمایش را دستی می‌سازند. این نسخه تا 14 روز به اجرای GitHub Actions خود پیوست می‌ماند و برای دانلود آن به حساب GitHub نیاز دارید.

نسخهٔ پیش‌نمایش نام بستهٔ خودش را دارد، `com.nb4a.throne.debug`؛ بنابراین با نمایه‌ها و تنظیمات جداگانه در کنار برنامهٔ پایدار نصب می‌شود. این نسخه خودش را به‌روزرسانی نمی‌کند و به‌روزرسان درون‌برنامه‌ای آن را پیشنهاد نمی‌دهد. در فرمان‌های adb و برنامه‌های خودکارسازی، به‌جای `com.nb4a.throne` از `com.nb4a.throne.debug` استفاده کنید.
