Get Started

What Throne is, which systems it runs on, and where to begin.

What is Throne

Throne (formerly Nekoray) is a free, open-source (GPL-3.0) proxy client for Windows, Linux and macOS. Its core, ThroneCore, is based on sing-box and also runs Xray for the profiles that need it. You add servers, choose which traffic goes through them, and connect in system proxy or TUN mode.

  • Throne for Android (formerly NekoBox for Android) uses the same core, settings and backup format, so you can move your setup between computer and phone.
  • Headless Throne runs without a window on a server, a router or in a container, controlled with thronectl.
  • If you used Nekoray or NekoBox before, read Coming from Nekoray / NekoBox.

Highlights

  • Many protocols, including VLESS with REALITY and XHTTP, Shadowsocks, Trojan, Hysteria, TUIC, WireGuard, AmneziaWG, NaïveProxy, OpenVPN, OpenConnect and DNS tunnels.
  • Subscriptions that update on a schedule.
  • System proxy, TUN mode and LAN sharing.
  • Routing rules, with ready-made profiles for China, Iran and Russia.
  • Latency and speed tests, and an Auto Selector that keeps you on a working server.
  • Proxy chains and custom configs, anti-censorship options such as TLS fragment, and built-in Cloudflare WARP.
  • A kill switch, and control with thronectl from scripts and other devices.
  • A Simple mode for new users, and Ctrl+K search for commands and settings.

Where to start

  1. Install Throne: Installation.
  2. Add your servers and connect: Quick Start.
  3. Read the Guides for the features you need.

On Android, start with Throne for Android. If something does not work, see Troubleshooting and the FAQ.

Credits
