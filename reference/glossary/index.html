Glossary

Short explanations of the terms you meet in Throne.

Profiles and groups

Term Meaning More
Profile One server or proxy entry in the list, with its protocol, address and settings. Quick Start
Group A tab of the main window that holds profiles. Subscriptions & Groups
Subscription A URL from your provider that returns a list of profiles, which Throne downloads into a group. Subscriptions & Groups
Share link A one-line link for one profile, such as vless://…, that other apps also understand. Protocols & Import Formats
Deep link A throne:// link that tells Throne to do something, such as add a subscription. Deep Links
Throne link A throne://add/… deep link that carries one profile of any type. Deep Links
Chain A Chain Proxy profile that sends traffic through several profiles one after another. Proxy Chains & Custom Configs
Front / landing proxy Group options that add one extra profile before (front) or after (landing) every profile of the group. Proxy Chains & Custom Configs
Auto selector A profile type that tests the servers of a group and uses the best ones automatically. Testing & Auto Selector
URL test A latency test that measures how long a profile takes to open a test URL. Testing & Auto Selector

Interface

Term Meaning More
Simple mode The interface mode of new installations, which hides advanced menu items and settings. Simple and Advanced mode
Advanced mode The interface mode that shows every menu item and setting. Simple and Advanced mode
Command palette A search window that finds menu commands and settings by name. Command palette

Core and connection modes

Term Meaning More
Core ThroneCore, the background program that carries your traffic. What is Throne
sing-box The open-source engine that ThroneCore is built on. sing-box vs Xray
Xray A second engine that runs inside the core for VLESS (Xray) profiles and Xray configs. sing-box vs Xray
Inbound A way for traffic to enter Throne, such as the mixed port or the TUN adapter. Inbound settings
Outbound A way for traffic to leave Throne: through a profile (proxy), directly (direct) or nowhere (block). Routing
Mixed port The local port that accepts both SOCKS5 and HTTP proxy connections. Inbound settings
System proxy The System Proxy mode, which points your system's proxy setting to the mixed port. System proxy
TUN The Tun Mode, which passes the traffic of all apps through a virtual network adapter. TUN Mode
Strict route A TUN option that stops traffic from going around the tunnel. Windows DNS Leak Protection
MTU The largest packet size of the TUN adapter. TUN settings

Routing and DNS

Term Meaning More
Routing profile A named set of rules plus a default outbound; one is active at a time. Routing
Rule A condition, such as a domain or a program, and the outbound for matching connections. Routing
Rule-set A ready-made list of domains (geosite-…) or IP ranges (geoip-…) for rules. Rule-sets
Default outbound Where a connection goes when no rule matches. Routing
warp-bypass An outbound that uses your profile but skips WARP. Cloudflare WARP
Remote routing profile A routing profile that Throne downloads from a URL. Remote profiles
Sniffing Reading the domain name from the start of a connection, so that domain rules also work for connections to IP addresses. Routing
DNS routing The Enable DNS Routing option, which resolves domains that match direct rules with direct DNS. DNS
Remote DNS / direct DNS The DNS servers used through the proxy (remote) and without it (direct). DNS settings
FakeIP A DNS mode that answers with temporary fake addresses and maps them back to the real domain names. FakeIP

Protocols and anti-censorship

Term Meaning More
Reality A security option for VLESS that makes the connection look like a visit to a real, unrelated website. sing-box vs Xray
XHTTP An Xray transport that carries the connection inside ordinary HTTP requests. sing-box vs Xray
uTLS Makes the TLS handshake look like that of a common browser. Anti-Censorship Presets
ECH Encrypted Client Hello, which hides the server name inside the TLS handshake. Anti-Censorship Presets
TLS fragment Splits the first TLS message into small pieces to get past some censorship filters. Anti-Censorship Presets
Multiplex (mux) Carries many connections inside one connection to the server. Anti-Censorship Presets
WARP The free VPN service of Cloudflare, which Throne can add as the last hop after your profile. Cloudflare WARP
MASQUE A tunnel protocol over HTTP/3 or HTTP/2, available as a profile type and as a WARP mode. Cloudflare WARP
DNS tunnel Carries your traffic inside DNS queries, for networks where only DNS gets through. DNS Tunnels
Resolver A DNS server that answers queries for you and, for a DNS tunnel, passes them on to the tunnel server. DNS Tunnels
mKCP An Xray transport that carries the connection over UDP. DNS Tunnels
XDNS A DNS tunnel in a VLESS (Xray) profile that sends mKCP packets as DNS queries. DNS Tunnels

Privacy, files and security

Term Meaning More
HWID A hardware ID that some subscription providers ask for. Privacy & Network Requests
OTP One-time passwords (TOTP or HOTP codes) that some OpenVPN and OpenConnect servers ask for. OTP Manager
.thrbackup The backup file of Throne, on the desktop and on Android. Backup and restore
Portable mode Throne keeps its data next to the program instead of in your user folder. Data folder
Kill switch A setting that blocks all traffic that does not go through Throne. Kill Switch

Automation and headless

Term Meaning More
Throne API An encrypted interface through which scripts and other devices control Throne with a secret key. Throne API & thronectl
thronectl The command-line client of the Throne API. Throne API & thronectl
Admin request A sensitive Throne API request that Throne answers only from its own computer, unless you allow the local network. Admin requests
Headless Throne Throne running without a window, for servers, routers and containers. Headless Throne
